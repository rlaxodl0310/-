# 플레이어 설정 없는 자체 모델 대화

플레이어는 게임 웹사이트에 접속해 평소처럼 대화한다. 브라우저에 모델이나 API 키를 설치하지 않는다. 게임 웹서버의 `/api/dialogue`가 같은 운영 환경의 Ollama 또는 llama.cpp에 요청하고, 대사 텍스트만 게임으로 돌려준다. 외부 AI 제공자 API를 사용하지 않는다.

## 운영하는 쪽에서 준비

Docker Compose가 있는 서버에서 저장소 루트에서 실행한다.

```sh
docker compose up --build -d
```

`model-prepare`가 서버에만 `qwen2.5:1.5b`를 처음 내려받는다. 모델은 `campus-models` 볼륨에 보존되고, 게임 컨테이너는 다운로드 완료 뒤 시작한다. 플레이어 화면에는 이 준비가 나타나지 않는다. 서버에서 `http://서버주소:8000/`를 제공하며 실제 공개 도메인·HTTPS 연결은 사용하는 호스팅 환경에서 설정한다. 이 명령은 현재 작업의 일부로 공개 서버에 실행하지 않았다.

기본 모델은 가벼운 연결 시제품용이며 사람 같은 한국어 품질을 보장하지 않는다. 더 큰 모델은 서버의 RAM/VRAM과 응답 속도를 확인해 선택한다. 예를 들어 운영 서버에서 모델을 바꿀 때는 준비 서비스와 게임 서비스가 같은 모델을 사용하도록 다음과 같이 지정한다.

```sh
CAMPUS_MODEL=qwen2.5:7b docker compose up --build -d
```

현재 Compose는 CPU에서도 실행할 수 있는 기본 구성이다. GPU 사용은 운영 서버의 NVIDIA Container Toolkit과 장치 설정에 맞춰 별도로 구성한다. GPU가 자동 연결된다고 가정하지 않는다. 운영 서버 인터넷은 최초 이미지·모델 수신 때 필요하며, 준비된 뒤의 대화 요청은 자체 서버 사이에서 처리한다.

## 이미 모델 서버가 있는 경우

Ollama가 같은 서버에서 실행 중이면 다음 환경으로 게임 호스트를 시작한다. 모델 파일은 미리 Ollama에 준비되어 있어야 한다.

```sh
CAMPUS_MODEL=qwen2.5:1.5b npm start
```

운영자용 환경 변수:

| 변수 | 기본값 / 의미 |
| --- | --- |
| `CAMPUS_MODEL` | 미지정 시 AI 서버 요청 없이 기존 로컬 조합 대화로 진행 |
| `CAMPUS_MODEL_PROVIDER` | `ollama`, 또는 자체 호스팅 `llamacpp` |
| `CAMPUS_MODEL_URL` | Ollama 기본 `http://127.0.0.1:11434/api/chat`; llama.cpp 기본 `http://127.0.0.1:8080/v1/chat/completions` |
| `PORT` | npm 실행 시 기본 `8000` |

llama.cpp의 OpenAI 호환 HTTP 형식을 지원한다는 뜻이며 외부 OpenAI 서비스 연결을 뜻하지 않는다. 모델 주소는 운영 서버 환경에만 있고 플레이어가 입력하지 않는다.

## 동작과 한계

- 브라우저는 같은 게임 사이트의 설정 상태를 한 번 확인하고 자동 연결한다. 게임 진행 전에 별도의 AI 켜기 화면을 띄우지 않는다.
- 실제 새 일대일 대화 턴에서만 추론하며 읽기·메뉴 복귀·불러오기에 재요청하지 않는다.
- 응답을 기다릴 때 시간이 흐르지 않고 중복 선택을 막는다. ‘기다리지 않고 이어가기’ 또는 통신 실패 시 이미 준비된 로컬 조합 대화로 진행한다.
- 서버 추론 시간은 최대 12초, 브라우저 대기는 최대 15초다. 느린 CPU나 큰 모델에서는 대체 대화가 자주 나올 수 있으므로 운영 서버에서 측정해야 한다.
- 모델은 발언만 만들며 선택지·관계 효과·아이템·약속·게임 시간은 변경하지 않는다. 자기소개에 필요한 이름 발언은 보존한다.
- 문맥에는 해당 인물의 성향, 현재 상태, 직접 들은 정보, 최근 같은 인물과의 대화만 보낸다. 모델 출력은 텍스트로 표시하고 게임 명령으로 실행하지 않는다. 모델의 잘못된 사실 언급까지 완전히 검증하는 기능은 아직 없다.
- 다운로드 ZIP의 `file://` 실행은 기존 오프라인 대화로 동작한다. 서버 AI 대화는 이 게임을 위 서버에서 서비스할 때 자동 연결된다. 모델을 HTML이나 ZIP에 포함했다고 표현하지 않는다.

## 검증

```sh
npm test
python3 -m unittest discover -s prototype -p server_test.py
python3 prototype/server_model_browser_smoke.py
```

브라우저 연동 검증은 시험용 추론 HTTP 서버를 사용해 웹/단독 HTML을 게임 서버에서 서비스하면서 응답 반영·실패 대체·사용자 대기 취소·저장을 확인한다. 실제 언어 모델의 품질·GPU 성능 검증과 구분한다. 현재 환경에서는 Hugging Face와 Ollama 레지스트리의 모델 다운로드가 HTTP 403으로 차단되어 실제 모델 추론을 실행하지 못했다. Compose 구성 검증은 통과했으며 이미지 빌드·모델 다운로드·공개 서비스 배포는 검증하지 않았다.
