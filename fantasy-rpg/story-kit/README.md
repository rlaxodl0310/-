# 이세계 표정·컷신·상호작용 제작 묶음

본편 설정과 별개인 **검토용 작성형 이벤트**입니다. 실제 AI 챗 화면에 연결했다고 표현하지 않으며 모델·키·추가 AI 호출 없이 살펴볼 수 있습니다. 각 인물 중심의 장면을 별도로 테스트합니다. 여경의 두 교복 이벤트만 태이를 화면 밖 대화 상대로 요구하며, 다른 세 이벤트는 기존대로 단독 상황입니다. 다른 인물의 동행·합류·같은 장소 체류를 요구하지 않습니다. 이는 실제 동료 합류·인물 이름 공개·아이템 획득·사건 순서의 확정이 아닙니다.

## 미리보기

저장소를 내려받은 후 이 폴더의 `index.html`을 열거나, 저장소 루트에서 아래처럼 실행합니다.

```sh
python3 -m http.server 8091 --bind 127.0.0.1
```

`http://127.0.0.1:8091/fantasy-rpg/story-kit/`에서 엽니다. GitHub 파일 페이지 자체는 실행 화면이 아닙니다. 로컬 파일 실행 시 브라우저에 따라 저장이 제한될 수 있으므로 같은 localhost 주소로 실행하는 편이 안정적입니다.

이벤트를 고르고 대사와 선택지를 확인합니다. **잠시 멈추고 목록으로** 이동한 뒤 다시 이어갈 수 있습니다. 진행 위치와 선택 기록은 별도의 브라우저 키 `fantasy-story-kit-v2-solo`로 저장되며 기존 AI 채팅·좀비 게임 저장을 건드리지 않습니다. 성공적으로 읽히지 않는 저장은 초기화 전까지 덮어쓰지 않습니다.

## 이벤트 모듈

- `data.js`: 인물·그림·장소/참여자 조건·분기·표정·SD 타일·완료 표시.
- `engine.js`: 조건 확인·선택 진행·직렬화/복원. 브라우저와 Node에서 같은 로직을 사용합니다.
- `app.js`: 표정 atlas를 CSS로 표시하고 대사·컷신·SD·선택을 연결합니다. 원본을 잘라 수정하지 않습니다.
- 기존 세 이벤트는 태이의 지도와 이정표, 도겸의 손목 보호대, 여학생의 우물가 새 관찰입니다. 총 14개 선택 경로를 검증합니다. 화면 속 발화자는 해당 인물 하나이며, 여경 이벤트는 별도로 대화 상대 태이를 확인합니다.
- 읽기·화면 재렌더만으로 시간이 흐르지 않습니다. 선택에 걸린 연습 시간은 완료 시에만 합산하며 중단 중에는 대기합니다. 완료된 이벤트의 시간과 표시를 중복 적용하지 않습니다.
- 시간은 이 검토판만의 연습 값이며 본편의 시간·마나·정수 타이머·공적·호감도를 변경하지 않습니다. 능력·직업·연애 관계를 부여하지 않습니다.
- 여학생 이름은 아직 가칭이므로 이벤트 화면에는 ‘같은 학교 여학생’으로 표시합니다.

실제 AI 진행에 연결할 때에는 모델이 반환한 캐릭터·표정·이미지 ID를 허용 목록에서 검증하고, 실제 장소·동행자·인물별 지식·이벤트 상태를 조회한 뒤 실행해야 합니다. 임의 모델 출력으로 조건·보상·세계 상태를 직접 바꾸지 않습니다.

## 검증

```sh
node --test fantasy-rpg/story-kit/tests/events.test.cjs
node --check fantasy-rpg/story-kit/app.js
```

조건 미충족·모든 분기·노드별 저장 복원·완료 중복 방지·잘못된 저장을 검증합니다. 실제 브라우저에서의 픽셀 배치·모바일 조작은 아직 확인하지 못했습니다. 전체 이야기의 자유 채팅과 실시간 이미지 생성 연결은 후속 범위입니다.

## 개별 이벤트로 수정한 기록

기존 세 사람 공동 컷신·SD 원본은 제작 이력으로 저장소에 남겨두지만 현재 미리보기에서는 참조하지 않습니다. 옛 공동 이벤트 저장은 v1 키에 보존하며 새 v2 개별 이벤트로 강제 변환하거나 덮어쓰지 않습니다. 현재 UI는 각 인물의 말과 행동을 검토하는 제작판입니다. 여경의 두 이벤트만 태이를 대화 상대로 명시하며 기존 세 이벤트에 태이의 존재를 추가하지 않습니다.
