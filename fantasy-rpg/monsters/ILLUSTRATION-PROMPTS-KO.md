# 몬스터 일러스트 재사용 프롬프트

검토 기준은 GitHub main 커밋 268d8ba다. 원본 생성 요청문을 복구한 문서가 아니라, 저장된 게임 도감과 원화에서 재구성한 제작 프롬프트다. 원화·공통 그림체 이미지를 실제 입력으로 함께 첨부해야 한다. 문장만으로 동일 얼굴·복장·그림체 재현이 보장되지는 않는다.

## 공통 그림체와 출력

첨부한 해당 몬스터의 승인 원화와 별도의 공통 그림체 기준을 참조한다. 승인 원화의 얼굴·실루엣·배색·무늬·재질·장식·무기·팔다리 수를 유지한다. 섬세하고 얇은 선화, 절제된 채도, 명확한 형태를 살리는 부드러운 명암으로 표현한다. 신체 전체가 여백 안에 들어오는 한 개체의 전신 일러스트. 캐릭터 바깥 배경은 투명 알파. 몸 내부의 반투명 재질과 흰 하이라이트는 보존한다. 글자·로고·바닥·외부 후광은 넣지 않는다.

## 추가 자세용 지시

위 종류별 외형 프롬프트와 함께 아래에서 하나를 선택한다. 각 자세는 한 장씩 제작하고 원화와 비교한다.

### 경계
기본 원화의 개체가 외부 움직임을 알아차린 경계 자세. 시선과 무게중심, 원래 있는 부속지만으로 긴장을 표현한다. 동일한 얼굴 구조와 팔다리 수를 유지한다.

### 공격
저장된 전투 방식에 맞는 동작을 사용한다. 앤트·키틴은 턱, 클래드는 압착 턱, 갱도라·코바르온·테라키온은 몸통과 머리 돌진, 피즈는 실제 삼지창, 그라우크·네르팽은 물기, 비리디온은 기존 잎날, 엠페르트는 볏 찌르기나 기존 지느러미 휩쓸기를 사용한다. 그 외 종도 원화의 실제 기관으로 공격한다. 생태 설정만으로 새 무기나 기관을 추가하지 않는다.

### 방어
자세를 낮추거나 기존 갑각·지느러미·잎날·날개로 핵심 부위를 보호한다. 코바르온은 팔 없이 두 다리와 몸통으로 버틴다. 네 다리 몬스터는 네 다리, 여섯 다리 몬스터는 여섯 다리를 유지한다.

### 피격
작은 충격을 받아 몸을 뒤로 기울이는 동작. 신체 일부를 중복시키지 않고 균형을 회복하는 순간을 표현한다. 재질·얼굴·장식은 원화와 일치한다.

## 일반 SD 일러스트용 지시

동일한 개체를 약 2~3등신의 작고 간결한 SD 비율로 표현한다. 얼굴 정체성·배색·장식·무기·무늬와 팔다리 수를 유지한다. 길쭉하거나 사족인 몬스터는 사람형으로 바꾸지 않고 머리와 몸통을 간결하게 압축한다. 매끄러운 일반 일러스트이며, 기본 전신보다 작게 표시할 자산이다. 투명 배경, 충분한 여백.

## 전투 도트 스프라이트용 지시

해당 몬스터의 승인 원화와 승인 SD를 참조한 선명한 픽셀 아트 시트. 4열×6행, 총 24프레임, 각 셀 256×256px, 전체 1024×1536px. 모든 프레임은 오른쪽을 바라보며 크기·카메라·발 디딤선을 통일한다. 행 순서는 대기·이동·공격·방어·회피·피격이고 각 동작을 4프레임으로 표현한다. 윤곽과 색 덩어리가 또렷한 제한 팔레트, 투명한 배경과 셀 사이 여백. 각 프레임마다 모든 신체 부위가 셀 안에 들어온다. 생성된 시트는 실제 프레임 크기·정렬·팔다리 수를 별도로 검수한다.

위 24프레임 규격은 향후 제작 템플릿이다. 기존 갱도라 등 일부 자산의 실제 동작 수와 규격은 다르며 기존 파일을 자동 변환한 것으로 해석하지 않는다. 왼쪽 방향으로 생성된 엠페르트 기존 시트는 방향 정보를 확인한 뒤 등록한다.

## 배경 컷신용 지시

종류별 외형 프롬프트와 승인 원화를 참조한다. 저장된 서식 환경과 생활 행동 중 한 장면을 선택해 16:9 배경 포함 장면으로 표현한다. 인물의 추가·무기·새 능력은 별도 요청에 따른다. 캐릭터와 배경의 광원·원근·접지 관계를 맞추고 얼굴·색·장식의 정체성을 유지한다. 글자와 UI는 넣지 않는다.

컷신 템플릿은 제작 제안이다. 실제 저장된 배경 CG는 네르팽 장면 및 일부 공용 시트 등으로 한정된다. 코바르온·테라키온·비리디온에 별도 배경 CG가 저장됐다고 뜻하지 않는다.
