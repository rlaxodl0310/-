# 이세계 기록 — 게임 기본 틀

기존 판타지 프로젝트와 설정을 사용하는 브라우저용 비주얼 노벨 체험판입니다. 정식 게임 이름과 본편 순서를 확정하지 않습니다.

- 배경 컷신, 대사, 선택지, 자유 텍스트 입력, SD 표시.
- 인물별 독립 이벤트 9개·18개 선택 경로.
- 상태창(임시 수치), 인물 제작실, 대화 기록, 글자/모션 설정.
- 브라우저 자동 저장, 수동 슬롯 3개, JSON 내보내기/가져오기, 중단과 장면 전환.
- 배포 링크의 자유 입력은 작성형 체험 반응이며, 개인 PC에서 Python 서버를 실행하면 ChatGPT 구독으로 로그인한 Codex CLI에 연결합니다. 즉석 이미지 생성은 아직 없습니다.
- UI와 진행 엔진, 체험 응답 어댑터를 분리했습니다. 체험 모드는 외부 모델 호출이 없으며, 로컬 AI 모드는 구독 사용량이 적용됩니다.

정수 획득·타이머·전투·레벨 상승·인벤토리 경제는 미구현입니다. 상태창 수치는 UI 테스트용입니다. 제작실은 플레이어가 알고 있는 인물 목록이 아닌 개발 자료입니다. 새 게임/장면 전환은 확인 후 실행하고 이전 수동 슬롯은 유지합니다.

`index.html`을 열거나 저장소 루트에서 `python3 -m http.server 8091` 실행 후 `/fantasy-rpg/game/`에 접속합니다. 테스트는 `node --test tests/game.test.cjs`입니다. 저장은 이 사이트의 브라우저에만 남으며 좀비 게임과 기존 story-kit 저장을 공유하지 않습니다.

Sites 관리형 환경의 브라우저 QA 도구가 없어 실제 화면·모바일·키보드 조작은 미검증입니다. 엔진 분기·저장 복원·중단·가져오기 검사와 JS 문법 검사를 수행했습니다.


## 실제 AI 연결 · ChatGPT 구독

이 게임 화면을 개인 PC의 Python 서버에서 실행하면 **브라우저 → localhost 서버 → ChatGPT 로그인 Codex CLI → 대사 JSON**으로 연결됩니다. 배포된 Sites 링크는 개인 PC의 구독 로그인을 사용할 수 없으므로 체험 모드이며, 설정의 ‘AI 연결 확인’은 localhost 실행에서만 작동합니다.

1. Python 3.11 이상과 공식 최신 Codex CLI를 설치합니다. https://learn.chatgpt.com/docs/cli
2. 터미널에서 `codex login`을 실행하고 **ChatGPT 계정**으로 로그인합니다. API 키 로그인은 사용하지 않습니다.
3. 저장소 전체를 내려받고 `fantasy-rpg/game/start-game.cmd`를 실행합니다. macOS/Linux는 해당 폴더에서 `python3 server.py`입니다.
4. **http://127.0.0.1:8092**를 엽니다. 상단에 ‘ChatGPT · 구독 연결’이 나오면 자유 입력창에 메시지를 보냅니다. 서버 창은 열어 둡니다.
5. 실행 파일을 못 찾으면 `FANTASY_CODEX_BIN` 환경 변수에 공식 CLI 경로를 지정합니다. 설치/인증 안내는 기존 `../chat/README.md`를 참고합니다.

구독 사용량과 계정별 한도가 적용되며 유료 API로 자동 전환하지 않습니다. 입력과 현 장면의 대화 기록은 OpenAI로 전송됩니다. 인증 토큰을 브라우저에 전달하거나 저장소에 저장하지 않습니다. localhost만 허용하며 이 개인 구독 서버를 공개 공유하는 기능은 없습니다.

서버는 현재 인물·현재 장면·그 장면의 성공한 AI 대화만 전달합니다. 작가용 설정집 전체와 제로의 숨은 정체를 보내지 않습니다. 모델은 대사/동작만 생성하고 스탯·아이템·이벤트 완료를 직접 변경하지 않습니다. 즉석 이미지 생성은 연결하지 않았습니다.

성공한 사용자 입력과 응답은 서버 `data/ai.sqlite3`에 기록됩니다. 쿠키와 DB가 유지되면 재시작 후 기억이 이어집니다. 장면별 40회 한도이며 설정에서 AI 기억을 초기화할 수 있습니다. 기존 JSON 저장 파일은 화면/이벤트 기록만 옮기며 서버 AI 기억과 쿠키는 옮기지 않습니다.

실패한 요청은 대화 기록에 반영하지 않고 입력을 유지합니다. 응답을 받지 못해 같은 말을 다시 보내면 같은 요청 번호를 재사용하여 성공한 응답을 재활용합니다. 실패나 시간 초과 중에도 실제 처리된 모델 사용량은 발생했을 수 있습니다. 클라이언트 연결 확인이 되지 않았을 때는 체험 모드임을 표시하며, AI 요청 실패를 가짜 모델 답변으로 대체하지 않습니다.

### 검증 범위

`python3 -m unittest discover -s tests -p 'test_ai.py' -v`와 `node --test tests/game.test.cjs`를 통과했습니다. 중복 요청·실패 시 저장 없음·장면별 기억·잘못된 출력·HTTP 접근 조건을 검사했습니다. 실제 Codex 로그인 상태는 확인됐지만 제작 환경의 Codex 저장 경로가 읽기 전용이어서 **실제 모델 응답 성공은 확인하지 못했습니다**. 사용자 PC의 로그인/실행과 브라우저 검증은 별도로 필요합니다.
