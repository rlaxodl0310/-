# 이세계 기록 — 게임 기본 틀

기존 판타지 프로젝트와 설정을 사용하는 브라우저용 비주얼 노벨 체험판입니다. 정식 게임 이름과 본편 순서를 확정하지 않습니다.

- 배경 컷신, 대사, 선택지, 자유 텍스트 입력, SD 표시.
- 인물별 독립 이벤트 9개·18개 선택 경로.
- 상태창(임시 수치), 인물 제작실, 대화 기록, 글자/모션 설정.
- 브라우저 자동 저장, 수동 슬롯 3개, JSON 내보내기/가져오기, 중단과 장면 전환.
- 체험 모드의 자유 입력은 인사·걱정/휴식·주변 확인에 대한 작성형 반응입니다. 그 외 입력은 미연결 안내를 표시합니다. AI 모델·이미지 생성·ChatGPT 구독 연결은 아직 없습니다.
- UI와 진행 엔진, 체험 응답 어댑터를 분리했습니다. 비용이나 외부 모델 호출이 발생하지 않습니다.

정수 획득·타이머·전투·레벨 상승·인벤토리 경제는 미구현입니다. 상태창 수치는 UI 테스트용입니다. 제작실은 플레이어가 알고 있는 인물 목록이 아닌 개발 자료입니다. 새 게임/장면 전환은 확인 후 실행하고 이전 수동 슬롯은 유지합니다.

`index.html`을 열거나 저장소 루트에서 `python3 -m http.server 8091` 실행 후 `/fantasy-rpg/game/`에 접속합니다. 테스트는 `node --test tests/game.test.cjs`입니다. 저장은 이 사이트의 브라우저에만 남으며 좀비 게임과 기존 story-kit 저장을 공유하지 않습니다.

Sites 관리형 환경의 브라우저 QA 도구가 없어 실제 화면·모바일·키보드 조작은 미검증입니다. 엔진 분기·저장 복원·중단·가져오기 검사와 JS 문법 검사를 수행했습니다.
