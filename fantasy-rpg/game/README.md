# 이세계 기록 — 브라우저 AI 웹게임

실행 링크: https://fantasy-story-taei.xodl0310.chatgpt.site

웹페이지 안에서 게임과 AI가 실행됩니다. **Python·Codex·계정 로그인·API 키가 필요하지 않습니다.** 기존 개인 PC용 실행기는 이 게임의 현재 실행 경로에서 제거했습니다. 정식 제목과 본편 순서를 확정하지 않은 제작용 비주얼 노벨입니다.

## 시작

1. PC용 최신 Chrome 또는 Edge에서 실행 링크를 엽니다. WebGPU와 하드웨어 가속이 필요합니다.
2. 상단 **AI 시작** 또는 설정을 엽니다.
3. 기본 모델 또는 경량 모델을 고르고 **모델 다운로드 후 AI 시작**을 누릅니다.
4. 준비가 끝나면 채팅창에 입력합니다. 위 선택지로 작성형 이벤트도 진행할 수 있습니다.

처음에는 WebLLM 실행 파일·모델·WASM을 외부 저장소에서 내려받습니다. 수백 MB~1GB 이상 전송과 GPU 메모리가 필요할 수 있습니다. 내려받은 모델은 브라우저 캐시를 재사용하지만 캐시 삭제·정책·네트워크에 따라 재다운로드가 필요하며 완전한 오프라인 동작을 보장하지 않습니다.

| 모델 | 용도 |
|---|---|
| Qwen 2.5 1.5B Instruct | 기본. GPU 메모리 약 2GB 이상 권장 |
| Qwen 2.5 0.5B Instruct | 경량. GPU 메모리 약 1GB 이상 권장, 표현력 낮음 |

실제 필요 메모리는 브라우저·GPU·정밀도와 다른 앱에 따라 더 큽니다. shader-f16을 지원하지 않는 GPU에서는 f32 빌드를 선택합니다. 작은 모델이므로 한국어 대화 자연스러움과 설정 준수는 대형 서버 모델보다 떨어질 수 있습니다.

## 비용·데이터

- 이 구현에는 과금형 모델 API 호출이 없고, 구독이나 결제 정보를 요구하지 않습니다. 모델 다운로드에 네트워크 데이터는 사용됩니다.
- 대화 생성은 브라우저 WebGPU에서 수행합니다. 앱이 대화 내용을 AI 서버로 전송하지 않습니다. 외부 호스트는 실행 코드와 모델 다운로드에 사용됩니다.
- WebLLM 0.2.88은 https://esm.run/@mlc-ai/web-llm@0.2.88 에서 버전을 지정해 불러옵니다. 모델은 MLC/Hugging Face의 공개 배포본을 사용합니다.
- 장면별 AI 대화 기억은 이 사이트의 브라우저 저장소에 남습니다. 게임 저장과 분리하며, AI 기억 초기화는 게임 저장 슬롯을 지우지 않습니다.

## 기능과 범위

배경 컷신·대사·선택지·자유 입력·SD, 독립 이벤트 9개/18선택 경로, 임시 수치 상태창, 인물 제작실, 대화 기록, 자동 저장, 슬롯 3개, JSON 내보내기/가져오기를 제공합니다.

모델 다운로드 진행률·준비 취소·답변 생성 중단·경량 모델 전환을 지원합니다. 지원하지 않는 기기는 안내를 표시하고, 사용자가 선택한 작성형 체험 모드는 별도로 표시합니다. 실제 AI 요청 실패를 작성형 반응으로 몰래 대체하지 않습니다.

AI에는 현 장면의 담당 인물 프로필과 같은 장면의 성공한 AI 대화를 제공합니다. 다른 인물의 대화나 작가용 설정집 전체를 보내지 않습니다. 모델은 대사와 자기 동작만 생성하도록 지시하며 스탯·아이템·시간·이벤트 완료를 바꾸지 않습니다. 작은 모델의 환각과 지시 불이행까지 보장하는 검증기는 아닙니다.

브라우저 AI의 문맥은 제한되어 있습니다. 장면당 최대 12회 또는 대화 본문 합계 약 1,800자를 넘으면 기록을 내보내고 AI 기억을 초기화하도록 안내합니다. 이전 대화를 몰래 버리지 않습니다. 게임의 JSON 저장은 화면/이벤트 기록을 옮기며 AI 기억과 모델 캐시는 포함하지 않습니다.

전투·레벨 상승·정수 타이머·경제·즉석 이미지 생성은 미구현입니다. 새 그림은 사용자가 일러스트 제작을 요청할 때만 제작합니다.

## 소스와 검사

이 폴더는 정적 웹 배포 파일입니다. assets는 상위 폴더의 ../assets를 사용합니다. HTTPS 정적 호스팅에 올리면 되며 별도 Python 서버가 필요하지 않습니다. 직접 소스를 열 때 file:// 실행은 모듈·Worker 제약이 있어 정적 호스팅을 사용해야 합니다.

`node --test tests/*.test.cjs`로 12개 검사를 통과했습니다. 장면 분기·복원·가져오기, GPU 미지원 안내, 모델 준비 진행, AI 실패 시 기억 보존, 준비/생성 취소, 장면별 기억 분리를 검사합니다. SDK의 모델 ID와 모델 설정/WASM URL도 확인했습니다. **실제 WebGPU 추론·한국어 품질·브라우저 화면·모바일 조작은 이 환경에서 검증하지 못했습니다.**
