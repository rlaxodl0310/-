# 이세계 기록 · 전투 실험실

별도 브라우저 전투 시제품. 본편의 현실 도입부나 저장 파일을 변경하지 않습니다.

- HTML 파일 직접 실행 또는 정적 호스팅. `dist/index.html`.
- 기능 검증용 도트 SD 전장: 입력 대기 중 판정 정지, 행동 후 연출, 인물/적 개별 개체 배치.
- 태이 단독 또는 도겸 동행 테스트, 고블린/슬라임/베스 1~5개체.
- 공격/강타/방어/회피/접근/후퇴/포션/도주, 제한된 한국어 행동 입력.
- 외부 AI 미연결: 문장 해석은 로컬 규칙입니다. 성공/실패/체력/자원은 엔진이 판정합니다.
- 중요한 태이-고블린/슬라임 장면에 준비된 일러스트를 재생합니다. 다른 인물 조합은 대체 컷을 강제로 사용하지 않습니다.
- 승패/도주/자원/난수/개체 상태 자동 저장. 본편과 별도 키 사용.
- 전투 수치는 임시입니다. 도겸 동행은 시제품 옵션이며 본편 합류 확정이 아닙니다.
- `npm install` 후 `npm test`로 판정 및 화면 초기화 검사(13개).
- 현재는 한 행동 후 아군/적 행동이 진행되는 초기 규칙입니다. 민첩 기반 독립 행동 게이지, 완전한 자연어 AI, 정수 보상, 실제 부상 시스템은 미구현입니다.

화면 초기화의 잘못된 DOM 선택자를 수정하고, 연출 오류 시 행동 잠금 복구 처리를 추가했습니다.

전체 화면을 채우는 전장 위에 대상 HUD와 행동 버튼·입력창을 겹쳐 표시합니다. 전투 기록·테스트 설정은 팝업으로 열고 데스크톱에서 전체 화면 전환도 지원합니다.
