# 이세계 기록 · 전투 실험실

별도 브라우저 전투 시제품. 본편의 현실 도입부나 저장 파일을 변경하지 않습니다.

- HTML 파일 직접 실행 또는 정적 호스팅. `dist/index.html`.
- 기능 검증용 도트 SD 전장: 입력 대기 중 판정 정지, 행동 후 연출, 인물/적 개별 개체 배치.
- 태이 단독 또는 도겸 동행 테스트, 고블린/슬라임/베스 1~5개체.
- 공격/강타/방어/회피/접근/후퇴/포션/도주, 제한된 한국어 행동 입력.
- 외부 AI 미연결: 문장 해석은 로컬 규칙입니다. 성공/실패/체력/자원은 엔진이 판정합니다.
- 중요한 태이-고블린/슬라임 장면에 준비된 일러스트를 재생합니다. 다른 인물 조합은 대체 컷을 강제로 사용하지 않습니다.
- 승패/도주/자원/난수/개체 상태 자동 저장. 본편과 별도 키 사용.
- 전투 수치는 임시입니다. 도겸 동행은 시제품 옵션이며 본편 합류 확정이 아닙니다.
- `npm install` 후 `npm test`로 판정 및 화면 초기화 검사(35개).
- 현재는 한 행동 후 아군/적 행동이 진행되는 초기 규칙입니다. 민첩 기반 독립 행동 게이지, 완전한 자연어 AI, 정수 보상, 실제 부상 시스템은 미구현입니다.

화면 초기화의 잘못된 DOM 선택자를 수정하고, 연출 오류 시 행동 잠금 복구 처리를 추가했습니다.

전체 화면을 채우는 전장 위에 대상 HUD와 행동 버튼·입력창을 겹쳐 표시합니다. 전투 기록·테스트 설정은 팝업으로 열고 데스크톱에서 전체 화면 전환도 지원합니다.

전장 카메라를 높은 사선의 넓은 시점으로 변경했습니다. 화면 크기·픽셀 밀도에 맞춰 캔버스를 생성하며 동일 배율 투영으로 화면 늘어짐을 방지합니다. 주변 숲길·지형을 넓히고 도트를 축소했으며 클릭도 같은 카메라 좌표를 사용합니다.

원화 기반 SD 픽셀 아틀라스(3열×5행, 대기/이동/공격): 태이·도겸·고블린·슬라임·베스. 몬스터 개체별 이미지를 재사용합니다.
로컬 전술 AI는 거리·체력·가드·무리 여부에 따라 추격/측면 이동/후퇴/경계/공격 준비/공격을 고릅니다. 외부 모델이 생각을 생성하는 방식은 아닙니다.
엔진은 행동별 독립 상태 스냅샷을 만들고, 화면은 판단 묘사 → 이동 보간 → 공격 자세 → 피해 순서로 재생합니다. 재생 중에는 최종 상태를 바로 노출하지 않으며, 저장은 확정 상태를 보존합니다. 연출 1×/2× 지원.

회피 선택과 공격을 피하는 순간에 사이드스텝·상체 기울임·낮추기와 이동 자세를 재생합니다. 이는 칸 이동이 아닌 일시 회피 동작이며, 무작위 빗나감과 회피 성공을 구분합니다.

이동 표현 보강: 캐릭터를 별도 화면 레이어로 표시하고 브라우저 네이티브 애니메이션으로 실제 출발점→목적점 이동·보행 프레임·회피를 재생합니다. 경로를 표시하고, 동작 줄이기 환경에서도 이동은 보이도록 필수 동작 시간을 유지합니다. 웹 자산 버전 쿼리로 이전 코드 혼용을 방지합니다.

머리 위에 개체별 HP 바·현재/최대 체력과 대상 테두리를 표시하며, 절반 이하 노랑·25% 이하 빨강으로 경고합니다. 피해 시 감소 잔상과 강조 효과를 표시합니다.

강타 고정 버튼을 스킬 메뉴로 교체하고 테스트용 집중 타격(MP6)·연속 타격(MP8)을 추가했습니다. 본편 습득 확정이 아닙니다. 공격 전진·방어 자세·스킬 준비 동작을 표시합니다. 상단 아군은 초상·HP/MP 현재최대·색상 바로, 적은 별도 묶음으로 표시합니다.

HP 바를 빨강(현재 체력, 즉시 감소) 앞층과 회색(감소 잔상, 1.2초 동안 추격) 뒷층으로 통일했습니다. 상단 HUD와 머리 위 바에 같은 시간 상태를 사용하여 재렌더링돼도 잔상이 초기화되지 않습니다. 회복은 두 층 모두 즉시 채웁니다. 이전 체력별 바 색상 변경은 대체했습니다.

테스트 설정에서 건틀릿/활/마법 전투 방식을 선택할 수 있습니다. 새 활·마법 픽셀 아틀라스(3열2행)의 대기/조준 또는 시전/발사 자세와 별도 화살·마력탄을 재생합니다. 원거리는 사거리4, 마법 기본공격은 MP2이며 방식별 임시 스킬이 있습니다. 투사체 이벤트 이후 피해를 표시하고 근접 전용 컷신을 원거리 전투에 사용하지 않습니다. 태이의 본편 무기·재능은 변경하지 않습니다.
