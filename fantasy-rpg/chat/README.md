# 태이의 이야기 · 개인용 ChatGPT 구독 연결

기본 연결은 **브라우저 → 개인 PC의 Python 서버 → ChatGPT로 로그인한 Codex CLI → 대사 JSON → 웹툰 패널**입니다. 기존 좀비 게임과 분리된 프로그램이며, 공개 서비스용 구독 공유 서버가 아닙니다.

## Windows에서 시작

1. Python 3.11 이상과 공식 최신 Codex CLI를 설치합니다. [공식 CLI 설치 안내](https://learn.chatgpt.com/docs/cli)를 따릅니다.
2. PowerShell에서 `codex login`을 실행하고 **ChatGPT 계정**으로 로그인합니다. API 키 로그인은 사용하지 않습니다. 이미 FMAX에서 쓰는 Codex가 설치되어 있다면 같은 PC의 로그인 상태를 활용할 수 있지만, 실행 경로가 다르면 확인해야 합니다.
3. 이 폴더에서 연결을 확인합니다.

```powershell
cd fantasy-rpg/chat
py -3 check_connection.py
```

4. `start-chat.cmd`를 실행하거나 다음 명령을 사용합니다.

```powershell
$env:FANTASY_PROVIDER = "codex"
py -3 server.py
```

5. 브라우저에서 `http://127.0.0.1:8090`을 엽니다. 로그인 직후 상태가 바뀌지 않으면 15초 뒤 새로고침합니다.

macOS/Linux에서는 같은 폴더에서 `python3 check_connection.py`, `python3 server.py`를 사용합니다. Python 외 패키지는 필요하지 않으며, Codex 설치·로그인은 사용자의 PC에서 한 번 준비합니다. 제작 환경에 설치된 CLI가 사용자 PC의 CLI라는 뜻은 아닙니다.

### 실행 파일을 못 찾는 경우

공식 네이티브 실행 파일의 경로를 환경 변수로 지정합니다.

```powershell
$env:FANTASY_CODEX_BIN = 'C:\설치경로\codex.exe'
py -3 check_connection.py
```

npm 설치의 `codex.cmd`가 검색되면 인접한 공식 `codex.js`를 Node로 직접 실행합니다. 셸 명령문에 대화를 넣지 않습니다. FMAX에 내장된 CLI 위치는 자동 추측하지 않습니다.

## 비용과 로그인

- 기본은 구독 로그인 경로입니다. API 키 로그인은 거부하고 자식 프로세스에서 OpenAI API 관련 환경 변수를 제외합니다. 공식 로그인 파일은 열거나 복사하지 않습니다.
- 구독에 포함된 Codex 사용량·계정별 한도가 적용됩니다. 무제한이 아니며 구독·크레딧 등 실제 계정의 이용 조건을 따릅니다. 프로그램이 크레딧을 구매하거나 유료 API로 전환하지 않습니다.
- 로그인 만료·한도·오래된 CLI·시간 초과 시 멈춥니다. 실패한 요청은 대화에 저장하지 않습니다. 수동 재시도는 가능하지만 실제 요청이 이미 처리됐다면 구독 사용량은 발생했을 수 있습니다.
- 입력·장면·대화 기록은 Codex를 통해 OpenAI로 전송됩니다. 브라우저에는 로그인 토큰을 전달하지 않습니다.
- 참고: [공식 인증](https://learn.chatgpt.com/docs/auth), [구독의 Codex 사용](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan), [스크립트 호출](https://learn.chatgpt.com/docs/non-interactive-mode).

## 대화와 기억

- 지하철 안 / 전송 직후의 **비정사 연습 장면** 2개. 임시 인물의 동기와 반응은 최종 설정이 아닙니다.
- 인물이 관찰한 사실·현재 동기·대화에서 들은 말만 전달합니다. 작가용 설정집 전체와 제로의 정체는 넣지 않습니다.
- 자연스러운 짧은 한국어와 관계에 맞는 말투를 지향합니다. 갑작스러운 친밀감·운명론적 상투어·장황한 설명을 줄이는 지침이 있습니다.
- 태이의 대사와 선택은 사용자가 입력합니다. 모델은 대사와 짧은 행동만 만들고 게임 상태를 변경하지 않습니다.
- 성공한 대화를 SQLite에 저장합니다. 쿠키와 DB가 유지되면 새로고침·서버 재시작 후 이어집니다. 같은 요청 ID는 기존 응답을 반환해 중복 기록을 막습니다.
- 장면당 40회이며 전체 장면 대화를 매 요청에 전달합니다. Codex 자체의 세션 기억에 의존하지 않습니다. 장기 기억 요약은 후속 단계입니다.
- 기록 내려받기·입력 초안 보존을 지원합니다. JSON 다시 가져오기는 아직 없습니다.

## 실행 제한과 한계

매 요청은 별도 임시 작업 폴더·읽기 전용·일회성 세션으로 실행합니다. 사용자 Codex 설정과 실행 규칙을 불러오지 않고, 셸·앱·브라우저·멀티 에이전트 도구를 비활성화하는 옵션을 지정합니다. 웹 검색을 끄고 stdin으로 대화를 전달합니다. 도구 실행 이벤트·미완료 응답은 저장하지 않습니다. CLI의 관리형 설정과 버전별 모든 동작까지 OS 차원에서 격리하는 장치는 아니므로 완전한 샌드박스나 사실 검증기로 표현하지 않습니다.

필수 옵션을 지원하지 않는 CLI는 약한 설정으로 실행하지 않고 업데이트를 안내합니다. 모델 선택을 생략하면 Codex 기본 모델을 사용합니다. 선택적으로 `FANTASY_CODEX_MODEL`에 계정에서 실제 사용 가능한 모델을 지정할 수 있습니다. API용 `FANTASY_MODEL`은 Codex 모델 선택에 쓰지 않습니다.

동시에 Codex 요청 하나만 처리하며 응답 제한 시간은 180초입니다. Codex 모드에서는 로컬 전용 주소와 Host를 요구합니다. 원격 PC의 ChatGPT/FMAX 창을 제어하는 방식이 아닙니다.

자연스러움과 사실 준수는 모델·입력에 따라 달라집니다. 코드가 검증하는 것은 JSON 구조·길이 등이며 모든 환각이나 프롬프트 공격을 차단하지 않습니다. 자동 이미지 생성·실제 장면 진행·제로 대화·기본 AI 어시스트·전투는 후속 범위입니다.

## 검증

```sh
python3 -m unittest discover -s tests -v
node --check public/app.js
```

기존 HTTP 모델 시험과 시험용 CLI의 실제 자식 프로세스 실행으로 입출력·저장·중복 전송·API 로그인 거부·한도 오류·시간 초과 종료를 확인합니다. **사용자 PC의 실제 ChatGPT 구독으로 대화한 검증은 아직 아닙니다.** Windows 실행 경로와 실제 브라우저 화면도 사용자 환경에서 확인해야 합니다. 실행 옵션은 제작 환경의 CLI 도움말과 공식 문서를 참고했습니다.

자세한 구성은 [설계 문서](DESIGN.md), 세계관은 [설정집](../WORLD_BIBLE.md)에 있습니다.

## 명시적으로 선택하는 기존 대안

OpenAI API·Ollama·자체 호환 서버 경로는 유지하되 자동 사용하지 않습니다. 직접 `FANTASY_PROVIDER=openai`로 선택하는 경우만 서버의 `OPENAI_API_KEY`, `FANTASY_MODEL`을 사용하며 별도 API 요금이 적용됩니다. `ollama`나 `compatible`도 운영자가 명시해야 합니다. 일반 사용 흐름에는 키 입력 화면이 없습니다.
