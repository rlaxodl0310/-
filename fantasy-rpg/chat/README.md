# 태이의 이야기 · AI 대화 시제품

좀비 게임과 분리된 `fantasy-rpg/chat` 전용 프로그램입니다. Python 3.11 이상만 필요하며 패키지 설치는 없습니다.

## 실행

```sh
cd fantasy-rpg/chat
python3 server.py
```

브라우저에서 `http://127.0.0.1:8090`을 엽니다. 모델 미설정 시 화면은 열리지만 대화는 생성하지 않으며, 고정 대사를 AI 답변으로 위장하지 않습니다.

### OpenAI API 연결

현재 ChatGPT 대화나 구독을 직접 연결하는 방식이 아닙니다. 운영자 OpenAI API 프로젝트와 키가 필요하며 API 사용료는 ChatGPT 구독과 별도입니다. 모델은 해당 프로젝트에서 접근 가능한 것으로 선택합니다. 다음 모델 이름은 연결 예시이며 최신·최적 모델이라는 뜻은 아닙니다.

운영자 서버의 비밀 환경 변수에 `OPENAI_API_KEY`를 설정합니다. 키를 코드·GitHub·플레이어 브라우저·대화창에 쓰지 마세요. 로컬 bash에서는 다음과 같이 화면에 표시하지 않고 입력할 수 있습니다.

```sh
read -rs -p 'OpenAI API key: ' OPENAI_API_KEY
export OPENAI_API_KEY
FANTASY_PROVIDER=openai FANTASY_MODEL=gpt-4.1-mini python3 server.py
```

`/v1/chat/completions`의 JSON 응답 형식을 사용하는 모델이 필요합니다. 실제 모델이 새로 생성한 대사만 표시하며, API 오류 시 입력을 남깁니다. 사용자의 입력·현재 장면·현재 대화 기록이 선택한 모델 서버로 전송됩니다. 키를 설정하고 요청을 보내면 모델 사용료가 발생할 수 있습니다.

### 자체 서버 모델 대안

```sh
FANTASY_PROVIDER=ollama FANTASY_MODEL=운영서버에_설치된_모델명 python3 server.py
```

기본 Ollama 주소는 `http://127.0.0.1:11434/api/chat`입니다. 모델을 자동 설치하거나 다운로드하지 않습니다. 자체 OpenAI 호환 서버는 `FANTASY_PROVIDER=compatible`, `FANTASY_MODEL_URL`, `FANTASY_MODEL`로 지정합니다. 선택적 인증키는 서버의 `FANTASY_API_KEY`입니다. 호환 서버는 `response_format: json_object`를 지원해야 합니다.

## 구현 범위

- 지하철 안 / 전송 직후의 **비정사 연습 장면** 2개. 임시 인물은 최종 캐릭터가 아닙니다.
- 자유 입력 → 실제 모델 호출 → 짧은 대사·행동 패널.
- 인물이 관찰한 사실·현재 동기·그 대화에서 들은 말만 모델 문맥으로 전달. 작가용 설정집 전체, 제로의 신격 정체, 전송자 처우는 해당 인물에게 전달하지 않습니다.
- 짧고 일상적인 한국어, 불필요한 설정 설명·즉각적인 친밀감·운명론적 상투어를 줄이는 연기 지침.
- 태이의 대사나 결정은 사용자가 입력. 모델은 상태창·아이템·레벨·정수·관계 수치를 변경하지 않습니다.
- SQLite에 성공한 사용자/모델 턴을 한 쌍으로 저장. 새로고침·서버 재시작 후 쿠키가 남아 있으면 이어집니다.
- 같은 전송 ID를 재시도하면 기존 응답 반환. 오래된 다른 탭의 덮어쓰기 방지. 실패한 모델 요청은 대화 기록에 반영하지 않습니다.
- 장면당 40회: 그 안의 **전체 대화**를 전달하며 오래된 기억을 몰래 버리지 않습니다. 장기 기억 요약은 후속 범위입니다.
- JSON 기록 내려받기, 장면 다시 시작, 입력 초안의 브라우저 임시 보존. 내려받은 기록을 다시 가져오는 기능은 아직 없습니다.

## 한계와 검증

자연스러움과 사실 준수는 모델·입력에 따라 달라집니다. 프롬프트는 완벽한 정보 유출/환각 방지 장치가 아닙니다. 출력의 형식·길이는 코드가 검증하지만 이야기 사실 전부를 판정하지는 않습니다. 모델이 관찰·관계 맥락을 어떻게 따르는지는 실제 연결 후 인물별로 평가해야 합니다.

```sh
python3 -m unittest discover -s tests -v
node --check public/app.js
```

테스트는 시험용 HTTP 모델로 연결 형식, 비밀정보의 문맥 제외, 실패 무저장, 중복 전송, 세션 격리, 쿠키 복원과 입력 검증을 확인합니다. 실제 OpenAI 추론이나 대사 품질을 검증했다는 뜻은 아닙니다. 현재 제작 환경에 키·모델이 준비되지 않아 실제 추론은 실행하지 않았습니다. 브라우저 자동 조작 도구도 없어 화면의 실제 브라우저 검증은 수행하지 않았습니다.

서버는 기본적으로 로컬에만 바인딩합니다. 이 Python 표준 라이브러리 서버는 개발용입니다. 공개 서비스 전에는 운영 서버·HTTPS·인증·요청 제한·이용량 예산·개인정보 보존 정책을 별도 구성해야 합니다. `HOST`, `PORT`, `FANTASY_DB`로 주소와 저장 경로를 설정할 수 있고 HTTPS 운영 시 `FANTASY_SECURE_COOKIE=1`을 사용합니다. 키는 절대 클라이언트 응답에 포함되지 않습니다.

아직 자동 웹툰 이미지 생성, 실제 장면 진행, 제로와의 대화, 기본 AI 어시스트, 게임 전투는 구현하지 않았습니다. 기존 세계관은 [설정집](../WORLD_BIBLE.md)을 따릅니다.
