# 세계관 통합 v0.8.0

## 포함한 자료

`world/WORLD_BIBLE.md`는 GitHub 세계관 설정집 62절까지의 스냅샷이다. 캐릭터·몬스터·성장·장비·경제·법·대륙·직업·마탑 설정과 기존 제안/미정 구분을 함께 보존한다. `world/manifest.json`에는 원본 GitHub blob과 파일 SHA256을 기록한다. 원문의 과거 제안보다 최신 수정·확정 항목이 우선한다.

마지막 대화의 마석 기원·충전·생활 마도구 보급률은 아직 저장/확정 요청 전의 제안이므로 확정 규칙에 편입하지 않았다. 직업·마탑 설정에 이미 채택된 마석 가공사·마도구 관련 직무는 유지한다.

## 실제 연결

- `ui/world/rules.js`: 대륙·세력·마탑·직업·성장·정수·특성·법률의 읽기 전용 구조화 기준이다. 전이자만 특성이 있고 슬롯을 사용하지 않는 규칙, 모든 성급 정수의 희소성, 48시간 던전 붕괴, 현지인의 성장 경로를 포함한다.
- `electron/world-context.cjs`: 승인된 핵심 규칙에서 용도별 AI 문맥을 만든다. 매 요청에 62절 전체를 전송하는 것은 아니다. 원문 전체는 번들에 보관하고 현재 기능에 필요한 핵심 규칙을 전달한다.
- `dialogue.cjs`와 `story-chat.cjs`: 현실 전송 이전에는 미래 설정을 전달하지 않는다. 기존 NPC 성격·관계 및 기억 처리와 함께 현실 지식 제한을 적용한다.
- `quest-board.cjs`: 대륙·세력·마탑·법률 등의 문맥을 전달한다. 공개 협회에는 합법 의뢰만 생성하도록 지시한다. 실제 보수·예치·기한·후보는 기존 엔진이 결정한다.
- `battle-judge.cjs`: 특성/정수/성장 등의 규칙을 전달하지만 현재 스냅샷과 보유 행동만 선택할 수 있다. 설정에 있는 능력을 자동 획득하지 않는다.
- 도감 → **알게 된 세계 기록**: 실제 엔진의 `knowledge_*` 플래그에 해당하는 항목만 표시한다. 현재 현실 스토리는 이세계 지식 플래그를 부여하지 않으므로 처음에는 비어 있다. 지식 해금은 향후 승인된 사건 노드가 발급하도록 준비했으며 AI 응답으로 플래그를 쓰는 경로는 없다.

## 법률 조회 함수의 범위

`assessLaw`는 살인·절도 등이 던전에서도 금지되는지, 증거가 부족한지, 재판 절차가 필요한지 등을 반환하는 순수 조회 함수다. 증거가 충분하더라도 자동 유죄 판결을 하지 않는다. 파산·중범죄의 노예화도 법원 절차가 필요하다는 값을 반환한다. 판결·각인·노예화·상속·재산 압류 등 실제 캐릭터 상태를 변경하지 않는다. 이 함수 자체가 모든 법률의 완성된 재판 엔진은 아니다.

공개 게시판의 불법 의뢰 금지는 AI 지침이며 자연어의 모든 위반을 결정적으로 탐지하는 완성된 검열기/법률 판정기를 구현한 것은 아니다. 기존 후보·JSON 필드 검증은 유지한다. 사용자 계정으로 실제 모델의 세계관 준수 품질을 별도 확인해야 한다.

## 저장과 패치

기존 이야기 저장 버전·완료 이력·동행·캐릭터 도감·경제 장부·로그인·외형팩은 바꾸지 않는다. 기존 저장을 신규 지식으로 자동 해금하지 않는다. 원문·공용 코드가 Windows ASAR에 포함되고 기존 자동 검색 패치로 교체된다. 실행 중인 앱을 종료한 후 패치한다.
