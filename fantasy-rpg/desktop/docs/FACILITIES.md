# 도시·마을 건물과 시설 v0.11.0

도시36곳·마을117곳에 대표 건물과 시설을 배치했다. 도시458개·마을535개로 총993개 항목이다. 정착지별 목록이며 실제 건축물 모델 또는 상점 거래993개를 완성했다는 뜻은 아니다.

## 구성

도시 기본은 잡화점·여관·식당/주점·무기/방어구점·대장간/수리소·경비 초소·진료소·학교·행정청/민원소·협회 접수소·기도소다. 항만 관리소·조선소·요새 지휘부·광물 가공장·화물 창고·마차 역참·연구/자료관 등은 기존 인프라에 따라 추가한다. 기존 마탑5곳과 황궁·교황청·대성당은 해당 도시에만 연결한다.

작은 마을 기본은 회관·공동 물 저장소·소규모 물자 교환소다. 생업에 따라 곡물 창고·방앗간·어구 작업장·생선 건조장·축사·과실 작업장·약초 건조장·가마·목재/직조 작업장 등을 둔다. 여관은 역참·숙박 기능이 있는 곳에, 치료소는 기존 설명에 있는 곳에만 둔다. 소바트에는 비행선 부품 작업장을 둔다. 모든 마을에 협회·은행·무기점·전문 치유 시설을 보장하지 않는다.

## 확인 방법

지도에서 방문한 도시/마을을 선택하면 **건물과 시설**이 표시된다. 시설 버튼을 누르면 역할 설명이 나온다. 미방문 장소의 목록과 설명은 숨긴다. 설정 자료 보기로 초안을 모두 확인할 수 있으나 방문 이력은 바뀌지 않는다. 별도 탐험 테스트에서도 같은 규칙을 사용한다. 다른 정착지의 건물 ID로 조회하면 반환하지 않는다.

## 자료·AI·범위

ui/map/facilities.js가 지리 자료의 인프라·생업으로 시설을 생성하며 world/buildings.json에 동일한 목록 스냅샷을 보관한다. 선택된 장소의 AI 문맥에는 그 장소의 실제 시설을 제공한다. 모든 마을에 임의로 여관·상점을 추가하지 않도록 지시하고 현실 장면에는 미래 시설을 보내지 않는다. 라이브 모델의 문장 준수 품질은 별도 확인 대상이다.

도착 후 공개된 시설 간판을 알 수 있는 수준의 자료다. 건물 내부 이동·건물별 별도 발견·주인·가격·재고·영업시간·역사·사건은 아직 정하지 않는다. 버튼은 설명 조회이며 실제 아이템 구매·수리·숙박·치료나 돈·재고 변경은 수행하지 않는다. 희귀 아티팩트의 상시 판매, 모든 대장장이의 에고 제작, 진료소의 고위 치유 보장은 추가하지 않는다. 기존 본편·탐험·돈·동행·외형·로그인 저장 형식은 유지한다.

## 검증

자동 검사74개 통과. 정착지153곳의 시설·고유ID·도시 특화·마을 생업·미방문 비공개·다른 장소 ID 거부·원화 조회 무해금·선택 AI 문맥을 확인했다. Chromium에서 시설 버튼과 소바트 작업장 설명, 기존 방문 저장과320/736px 시연을 확인했다. 실제 사용자 계정 로그인·실시간 모델 품질은 별도다.
