# 탐험 지도 v0.9.0

## 사용법

왼쪽 **지도** 또는 이야기 화면의 작은 지도를 누른다. 현재 구역과 세계 지도를 전환할 수 있고, 세계 지도에서 대륙을 누르면 해당 대륙의 상세 지도가 열린다. 상세 지도의 **세계 지도** 버튼으로 돌아간다. 아직 방문하지 않은 대륙도 선택 가능하지만 이름·지형을 공개하지 않고 검은색 물음표로 표시한다.

실제 방문은 이야기 엔진이 장면에 진입한 위치에서 기록한다. 지도 클릭·선택·원화 감상은 방문으로 계산하지 않는다. 현재 본편은 현실 지하철에서 시작하며 이세계 도착 장소를 임의로 지정하지 않는다. 현실 지도는 지하철·승강장·대합실의 개념적 연결도이며 실제 서울 지리나 특정 역 도면이 아니다.

## 탐험과 저장

- 본편 `Engine.state.visitedLocations/currentLocation`은 승인된 이벤트 시작 이력에서 도출한다. 반복 방문은 중복 기록하지 않는다.
- 기존 저장 형식과 버전을 유지하고 과거 이력을 재생해 실제 진입 장소를 복원한다. 미방문 대륙을 자동 해금하지 않는다.
- 대륙 상세 구역에 진입하면 해당 구역과 상위 대륙만 발견 상태가 된다. 같은 대륙의 나머지 구역과 다른 대륙은 숨긴다.
- 현재 상세 지도는 대륙당 9구역, 총45구역을 지원한다. 구역명은 지형을 설명하는 제작용 표제다. 기존 이세계 이벤트의 마을을 어느 대륙에 둘지는 미정이므로 강제로 연결하지 않는다.
- 자유 AI 이야기 테스트의 방문 기록은 별도 저장에 남기며 본편 탐험과 합치지 않는다. 모델이 제안한 장소는 기존 연결·이동 요청·패널 검증을 통과하고 저장된 경우만 기록한다.
- 구형 AI 이야기 기록은 현재 위치만 확실히 복원한다. 저장되지 않은 과거 이동을 추측해 해금하지 않는다.

## 원화와 지리 시안

세계 지도1장과 대륙 상세 원화5장을 제작했다. **지도 원화 보기 · 설정 자료**는 명시적으로 여는 제작 자료다. 전체 원화에서도 대륙 클릭→상세 원화를 지원하며, 탐험 기록은 바뀌지 않는다.

| 대륙 | 시각적 기후·지형·생태 방향 |
| --- | --- |
| 노르가르 | 북단 설산·냉량 지역, 중부 침엽수림·산록, 남부 온대 경작지. 최북단 요새도시와 방위 시설. |
| 엘세리아 | 습윤한 숲·호수·습지·구릉·하구. 마법 교육·생태 관측 시설. |
| 카르덴 | 산맥·고원·건조한 내륙 초원과 온대 해안·하천 평야. 광산·제련·공방. |
| 세르바 | 따뜻한 해안·계절림·사바나·삼각주·일부 건조 구릉. 항구·교역망. |
| 아르켄시아 | 온대 평야·대하·호수·숲과 산릉. 더 조밀한 도시·도로·행정 및 종교 중심지. |

동서남북의 전반적인 발전 수준은 비슷하다. 북부 전체를 설원, 서부 전체를 황무지처럼 한 가지 환경으로 만들지 않는다. 중앙만 전반적 기반 시설이 더 발전한다. 원화의 실제 해안선·산맥·도시 점 위치·상세 기후 구획은 검토 가능한 지리 제안이지 최종 세계관 좌표가 아니다. 세계 지도와 상세 원화는 서로 독립 제작된 시안으로 정확한 해안선·좌표를 공유하는 GIS/연속 줌 지형은 아니다. 여행 경로·거리·소요 시간·새 도시 이름을 자동 확정하지 않는다.

## 검증과 범위

엔진 방문·구형 저장 재생·잘못된 이동 거부·대륙/상세 구역 해금 범위·AI 테스트 저장 분리를 자동 검사한다. Chromium에서 본편 미니맵과 지도 메뉴, 미탐험 대륙 선택, 원화 확대가 방문 기록을 바꾸지 않는지 확인한다. 현재 이세계 이동 사건과 자유 이동 조작은 아직 본편에 추가하지 않았으며, 지도 원화를 누른다고 이동하지 않는다. 별도 채팅 시연의 이동은 테스트 이력만 변경한다.

검증 결과: 자동 검사64개 통과. 세계 원화와 대륙5장의 PNG 포함·크기·중복 여부까지 확인한다. 실제 Chromium에서 대륙5곳의 원화 로딩, 세계↔대륙 전환, 1/9 구역 공개, 원화가 방문 이력에 영향을 주지 않는 동작, 320/736px 폭과 라벨 최소 가독성을 확인했다.
