# 평소 일러스트 외형팩 · v1

Windows 앱 v0.4.0 이상에서 상단 **외형팩** → **외형팩 파일 불러오기**를 선택합니다. PNG와 연결 정보를 묶은 JSON 형식의 `.lookpack` 파일 하나입니다. 이후 팩 추가는 앱 패치 없이 가능합니다. 배경/컷신/전투 SD를 바꾸는 기능이 아니라 평소 대화 인물 일러스트 교체 기능입니다.

예제 팩 추가 버튼으로 교복 표정 시트 및 태이의 이세계 격투가 미리보기를 시험할 수 있습니다. 이세계용 외형은 현실 장면에 자동 적용되지 않습니다. 현재 본편은 현실 도입부라 이세계 외형은 미리보기로 확인합니다.

```json
{
  "format": "fantasy-lookpack",
  "version": 1,
  "id": "taei-chitin-outfit",
  "name": "태이 갑각 건틀릿 외형",
  "images": [{"id": "portrait", "mime": "image/png", "data": "PNG의 base64 문자열"}],
  "looks": [{
    "id": "taei-chitin",
    "characterId": "taei",
    "era": "fantasy",
    "equipment": {"weapon": "chitin-gauntlets"},
    "image": "portrait",
    "layout": {"columns": 1, "rows": 1}
  }]
}
```

- IDs: 영문으로 시작, 영문/숫자/밑줄/하이픈 최대64자.
- `characterId`: 게임 인물 ID. 예: `taei`, `yeogyeong`, `dogyeom`, `seoha`, `yui`.
- `era`: `earth`, `fantasy`, `any`.
- `equipment`: `outfit`, `weapon`, `armor`, `accessory` 중 필요한 장비 ID. 모두 일치해야 표시됩니다. 빈 객체면 그 인물·시대 기본 외형입니다.
- `layout`: 단일 그림은1×1, 표정 시트는 실제 배열. 최대8×8. 표정 인덱스는 게임 순서를 쓰고 범위를 넘으면 마지막 칸을 사용합니다.
- 같은 조건이면 구체적인 장비 조합이 우선, 그 다음 최근 불러온 팩이 우선입니다. 이전의 다른 팩은 비활성화하여 충돌을 피할 수 있습니다.
- PNG만 지원. 파일32MB, 이미지당8MB, 합계24MB, 최대4096×4096, 전체32메가픽셀, 이미지24개·외형48개 제한.
- 팩에는 실행 코드·외부 URL·임의 파일 경로를 넣지 않습니다. 파일 선택 후 검사·복사하며 기본 앱 파일은 덮어쓰지 않습니다.
- 선택 장비는 저장 슬롯/내보내기와 함께 보관합니다. 예전 저장은 기본 외형으로 불러오고 등록된 팩 자체는 PC 사용자 데이터의 `appearance-packs`에 보관합니다.
- 현재 장비 선택은 외형 연출용입니다. 실제 장비 소유/스탯/제작 엔진은 별도이며 추후 그 착용 상태를 같은 ID 연결에 넣을 수 있습니다.
- 이미지를 부분 레이어로 분해하는 도구는 포함하지 않습니다. 현재는 완성된 일러스트 또는 표정 시트를 교체합니다.
