# 도시 구역 지도 · v0.13.0

반복되는 건물 구조 지적을 반영해 모든36개 도시,108개 구역을 독립된 지형·길망·건물 덩어리로 교체한다. 먼저 만든 케스윅·미루카·티몬과 나머지33곳을 함께 적용한다.

도시명·구역명·대륙·지리 정보를 표시한다. 시설은 구역별 버튼으로 역할을 확인하며 그림과 관계없는 고정 좌표에 건물 표식을 붙이지 않는다. 전체 시설 목록은 유지한다. 지도 선택은 실제 이동이나 건물 입장이 아니며 저장·발견·시간·화폐·동행을 바꾸지 않는다. 미방문 도시는 기존처럼 숨기고 설정 자료 보기로만 전체를 열람한다.

마을·야생지역의 추가 일러스트는 이번 도시 교체 패치에 포함하지 않는다. 중단했던 작업 파일은 별도 초안으로 보존했다. 기존 시설·지리·세력 설정은 유지한다. [도시별 구조](CITY-ATLAS.md)를 참조한다.
