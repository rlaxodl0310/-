# 도시 구역 일러스트 · v0.12.0

이제36개 도시마다 별도의 그림을 사용한다. 총108개 거리 장면이며 도시별3개 구역을 화살표로 오간다. 발크의 기존 그림은 유지하고35개 도시 그림을 추가했다. [도시별 구성](CITY-ATLAS.md)을 따른다.

도시 시설 목록을 모두 그림에 끼워 넣지 않는다. 화면마다2~3개 해당 건물만 표시한다. 도시 선택과 구역 전환은 지도 열람이며 실제 위치·발견·시간·화폐·동행을 바꾸지 않는다. 방문한 도시 또는 설정 자료 보기에서만 보여준다. 실제 내부 입장·거래는 후속 작업이다.

화면 위에는 대륙·도시의 지리 정보를, 그림 안에는 도시명과 구역명을 표시한다. 각 건물 버튼에는 기존 시설명을 표시한다. 새 점포 주인이나 상호를 임의로 확정하지 않는다.
