# 도시 구역 일러스트 · v0.11.2
발크의 높은 조감도 대신 가까운 거리의 중앙 시장·서부 공방 골목·동부 강변 3개 장면을 사용한다. 같은 그림을 좌우로 밀지 않고 방향 화살표마다 서로 다른 건물 배치의 장면으로 전환한다.

중앙 시장은 잡화점·협회·장비점, 공방은 대장간·제작 공방, 강변은 진료소·기도소를 표시한다. 기존 나머지 시설은 도시 시설 목록에 유지하며 이 3개 장면에 모두 끼워 넣지 않는다. 그림은 하나의3단 이미지에서 각 구역을 화면 배경으로 분리해 사용한다. 실제 내부 입장·거래·이동 시간 처리는 미구현이며 지도 열람만 바뀐다.

기존 방문/설정 자료 보기 조건과 저장은 유지한다. 다른 정착지는 아직 시설 목록이다.

검증: 기존 검사74개 통과. 실제 앱 브라우저에서 시장→공방→시장→강변 전환, 구역별 건물 수와 역할 설명, 미방문 숨김 확인.
