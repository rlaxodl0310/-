# 도시 일러스트 지도 · v0.11.1

발크(west-city-01)에 우선 적용한 조감도 초안이다. 산기슭 광산과 공방, 중앙 시장과 협회, 동부 강변 의료·종교·경비 구역을 시각적으로 배치한다. 기존 등록 시설 13개를 그림 위 버튼으로 연결한다. 광산·시장·마구간 등 배경 건축물은 지형 묘사이며 별도 서비스 구현을 뜻하지 않는다.

도시 정보에서 지도 열람, 좌우 버튼과 드래그 이동, 확대 및 전체 보기를 제공한다. 건물 버튼은 역할 설명을 보여주며 실제 이동·구매·숙박·거래는 일어나지 않는다. 방문한 도시 또는 명시적인 설정 자료 보기에서만 표시한다. 도시 방문을 건물 내부 방문으로 취급하지 않는다.

다른 도시·마을에 이 그림을 재사용하지 않는다. 현재 상세 일러스트는 발크 한 곳이며 다른 정착지는 기존 시설 목록을 유지한다. 좌표는 이 그림에 맞춘 초안으로 대륙 좌표·실제 도로거리와 연동하지 않는다. 후속 도시는 각 지역의 지형·생업·기존 시설에 맞게 별도로 제작한다.

검증: 기존 Node 검사74개 통과. 실제 앱 Chromium에서 시설13개·설명·좌우 이동·전체 보기·미방문 숨김·390px 너비 확인.
