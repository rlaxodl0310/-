# 개인·공용 스킬 엔진 · v0.27.0

공용 액티브181항목을 원문과 고정ID로 보존한다. 개별 등급은 고정이며 숙련과 별개다. 체력/마나 스탯1=HP/MP100이다. 실험실은 확정 설정이 아니며 본편에 시험 능력을 지급하지 않는다.

## 경계

- `ui/skills/system.js`: 브라우저/Node 공용 레지스트리, 출처·경험 검증, 파생 비용, 시전 영수증, 숙련, 설명.
- `electron/story-skills.cjs`: 이전 저장에서 검증한 AI 제안의 등록, 현재 플레이어의 이름 기반 사용, 실제 일반 전투 결과 기록, 실시간 복귀의 제한된 병합.
- `ui/realtime/engine.js`: 준비/중단, 실제 타격 범위·투사체 충돌·방어·이동·회복의 실행. 수치/소유권 검사는 공용 모듈을 다시 사용한다.
- `ui/skills/effects.js`: 열거된 색·형태의 절제된 Canvas 효과. 외부 코드/URL/셰이더 입력을 실행하지 않는다.
- `ui/skills/lab.*`: 시험 전용 능력/적을 만든 독립 실험실. IPC/본편 저장/모델 호출이 없다.

## 신뢰하는 입력

`grant`는 게임 코드가 실제 획득을 완료한 출처만 등록할 내부 API이다. AI 제안/채팅에는 노출하지 않는다. 정수 흡수·에고 획득 전체 흐름과 아직 연결되지 않았다. 현재 자동 생성하는 출처는 실제 맨손 적중3회에 따른 물리적 수련 근거뿐이다.

`practice`와 `incoming`은 실제 판정 콜백에서만 부른다. 반복 이벤트 ID, 무효/음수 수치를 거른다. AI가 출력한 피해량은 경험으로 취급하지 않는다. `register`는 이전 저장의 활성 출처·동일 소유자의 서로 다른 경험3개를 확인한다. 이름을 바꾸어 같은 실행 정의를 중복 등록할 수 없다.

`prepare`는 자원과 조건을 검사한다. `consume`은 같은 검사를 반복하고 쿨타임/충격/시전 영수증을 기록한다. 실제 HP/MP 소모는 해당 어댑터가 적용한다. `award`는 알려진 소유자의 시전 영수증과 실제 유효 결과가 있어야 한다. 같은 시전은 여러 적을 때려도1회만 숙련을 받는다. 전투당 경험20, 숙련 단계별 제한된 효율 보정만 적용한다.

## 지원 범위

개인 기술 템플릿은 `strike`, `bolt`, `guard`, `dash`, `mend`이다. 공용 기술은 별도 정적 도감의 복합 효과를 공용 전투 어댑터에서 실행한다. `mend`는 현재 UI에서 자가 회복으로 제한한다. 반격 순간과 저장 충격 조건을 지원하되 실제 피격 기록이 필요하다. 방어/이동은 단순한 버튼 사용이 아닌 실제 차단량/위협 근처 실제 이동으로 숙련을 받는다. 임의의 새 규칙·소환·시간 정지·모든 특성·아군별 일반 전투 HP를 구현한 것은 아니다.

일반 전투는 판정 전에 현재 시각을 검사한 뒤 한 차례의 공방 시간을 전진한다. 반격은 직전 피격 직후 사용 가능하다. 일시정지는 실시간 시각을 멈추며 예약은 재개 시 재검사한다. 중단된 시전의 자원은 환불하지 않고 숙련을 부여하지 않는다.

## 저장과 검증

기존 저장에 `skillBook`을 더하며 초기화하지 않는다. AI 응답/묘사의 최종 검토가 끝난 뒤 전체 이야기 상태와 함께 저장한다. 실패에는 원래 HP/마나/기술/숙련을 보존한다. 요청 재시도와 직전 저장 복구도 같은 경계를 따른다.

실시간 복귀는 토큰·전투·이야기 revision을 검사하는 기존 경계 안에서 처리한다. 클라이언트가 기술 정의를 추가/변경하거나 능력 근거를 임의로 지급하지 못하도록 비교한다. 허용한 수련 이벤트만 재적용하고 숙련 증가/사용 횟수/피격·쿨타임 수치의 한도를 검사한다. 기존 HP와 같이 실제 적중 결과는 로컬 클라이언트를 신뢰한다. 서버 재연산형 검증이나 부정행위 방지라는 의미가 아니다.

자동 검사는 제안 권한/출처·소유권/장비 해제/반격 시점/중복 시전·숙련/빗나감·취소/투사체·방어·회복·이동/일시정지/저장·재시도·복구를 다룬다. 실제 ChatGPT의 자연어 제안 품질은 별도 검증 대상이다.

## 공용 도감과 시험 경계
`common-data.js`는 원문181항목의 고정ID/등급/MP와 조정 가능한 실행 계수를 분리한다. `common.js`는 권한/무기/거리/자료를 검사하고, `common-battle.js`는 실제 피해/상태/이동/허상/물건/혈흔을 적용한다. `common-chat.js`는 같은 전투 엔진으로 일반 공방을 판정하고 임시 상태를 이어간다. 반사/관통/다중 타격은 실제 투사체·충돌·판정 콜백을 사용한다. 실제 혈흔이 없으면 혈흔 추적은 실패한다.

`learnCommon`은 게임 코드가 검증한 학습 근거를 넣는 내부 API이다. AI의 개인 기술 제안으로 공용 도감의 습득을 위조하지 않는다. 수련3회/1분/소량MP는 시험 정책이며 확정 설정이 아니다. 교사/교본 습득 이벤트 전체는 아직 연결 대상이다. `catalog.*`와 대화 내 시험장은 시험용 습득 상태만 만들며 실제 저장/모델 호출을 하지 않는다.

`resources.js`는 자원 변환과 구버전 비율 보존을 담당한다. 신규 기본값1은 시험 시작값이며 모든 인물의 확정 스탯이 아니다. MP는 스탯 포인트와 혼동하지 않고 실제 자원 단위로 차감한다. 공용 기술은 원문 MP를 유지하고 개인 기술 대표 비용은 등급 구간 안에서 계산한다. 쿨타임은 없지만 준비/회복 동작은 생략하지 않는다.

비전투 생활 기술도 같은 판정 엔진을 사용한다. 확인한 물건의 이름을 지정해 견인/진동을 사용할 수 있고, 살아 있는 적이 필요한 공격은 적 없이 실행하지 않는다. 적이 없는 생활 사용을 위해 가상의 몬스터를 만들지 않는다. 실제 물건 상태와 임시 효과를 보존하고 세계 시간 경과에 맞춰 잔여 지속시간을 계산한다.
