# 지리·도시·마을 연결 v0.10.0

## 실제 적용 자료

GitHub 설정집66절까지의 원문과 도시·마을 JSON, 야생지역 초안을 앱 world/에 포함했다. manifest의 원본 blob과 파일 SHA256을 함께 갱신한다. UI와 Electron이 함께 읽는 GeographyData/GameGeography에는 도시36곳·마을117곳·자연 권역18곳·동굴 세부 장소10곳, 총181개 장소가 있다. 야생610곳은 제작 목표로만 남기며 미작성 지명을 자동 생성하지 않는다. 소바트는 마을, 케스윅은 북부 요새도시다.

## 지도에서 확인

**지도 → 지상 지도 → 대륙 → 도시/마을/야생지역**을 선택한다. 미방문 장소는 이름·위치 설명·인프라/생업을 숨기고 물음표로 표시한다. 장소 표식과 목록 모두 선택 가능하다. 자연 권역의 ‘안쪽 장소 보기’로 동굴 세부 장소를 열 수 있다. **공중 지도**는 아엘리온을 연다.

설정 자료 보기 체크는 제작용 목록과 원화를 공개하되 실제 방문을 기록하지 않는다. 아엘리온은 기존 여섯 대륙 원화의 공중 영역을 SVG 뷰포트로 확대한다. 도시·마을 표식 좌표는 읽기 쉬운 임시 배치이며 원화의 건물 점 또는 정사 거리와 일치한다고 보장하지 않는다. 정확한 항로·도로·좌표·이동 시간·운임을 확정하지 않는다.

## 방문 해금과 저장

본편은 승인된 이야기 이벤트의 location이 등록된 장소 ID일 때 기존 Engine의 방문 기록에서 해금한다. 현재 현실 도입부를 임의로 이세계로 이동시키지 않는다. 구형 대륙 격자 방문은 대륙 발견만 유지하고 새로운 도시·마을을 자동 해금하지 않는다. 장소 하나에 방문해도 같은 대륙의 이웃 장소나 동굴 자식 장소는 공개되지 않는다. 기존 본편 저장·동행·시간·경제·로그인·외형은 유지한다.

**지도 → 탐험 테스트 · 본편과 분리**에서 181개 장소를 직접 선택하고 ‘이 장소 방문 · 별도 테스트’를 눌러 동작을 검증할 수 있다. 테스트도 실제 StoryKitEngine의 이벤트 이력을 이용하며 별도 localStorage 키 `fantasy-geography-test-v1`에 저장한다. 재실행·재방문을 지원하고 손상된 원본은 덮어쓰지 않는다. 이 버튼은 실제 도보·마차·배·비행선 여행을 시뮬레이션하지 않으며 본편의 플레이어 위치를 바꾸지 않는다.

## AI와 미구현 범위

세계관 공용 자료에 아엘리온을 추가했다. 의뢰/판타지 문맥에는 여섯 대륙과 주요 도시 이름·이동수단의 기본 연결·등록 장소 범위를 제공한다. 선택 장소 문맥은 등록 ID만 허용한다. 현실 이야기에는 미래 지명을 보내지 않는다. 117개 마을 설명을 매 요청에 모두 넣는 방식은 아니다.

실제 도시별 자유 스토리·상점·마차/선박/비행선 운행·NPC·의뢰 사건과 여행 비용은 후속 작업이다. 이번 버전은 저장된 설정을 지도·정보·해금 조회와 AI 기준에 연결한 것이다. 기존 별도 AI 이야기 테스트의 현실 이동 기록은 본편과 합치지 않는다.

## 검증

자동 검사70개: 지명·분류·중복 ID·마을 수, 미방문 정보 비공개, 이웃/자식 미해금, 방문 이력 재생·기존 격자 호환·원화 조회 무변경·AI 문맥을 포함한다. Chromium에서 본편/테스트 저장 분리, 도시·마을 방문과 재시작 복원, 아엘리온12개 마을/소바트, 320/736px 채팅 시연을 확인했다. 실제 Windows 사용자 계정 로그인·라이브 모델의 서술 품질은 별도 확인 대상이다.
