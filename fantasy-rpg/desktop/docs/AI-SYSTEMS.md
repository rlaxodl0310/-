# 의뢰 생성과 실시간 이야기 · v0.5.0

## 실행
상단 **의뢰 테스트** 또는 **AI 이야기**를 누른다. 설정에서 기존 공식 ChatGPT 구독 로그인 사용. 별도 API 키나 유료 API 자동 전환 없음. 구독 Codex 한도가 적용된다.

의뢰 테스트: 상황 선택 → AI로 새 의뢰 생성 → 항목 클릭 → 상세/신청. 오프라인 동작은 `로컬 예제 생성`으로 명시적으로 선택. AI 호출이 실패하면 기존 기록을 보존한다. 테스트 신청자 D랭크, 임시 금액/공적 수치. 상인단 호위·의뢰인 호위·몬스터 토벌·던전 공략·생태계 조사·마석 채굴·재료 조달·구조를 지원한다. 종류는 확장 가능한 데이터로 정의한다.

AI 이야기: 김태이로 말하거나 행동을 입력. NPC 대사/주변 묘사/기존 표정 시트를 연출한다. 현실 지하철·승강장·대합실과 여경을 대상으로 하는 개발용 자유 진행 테스트다. 기존 본편과는 별도이며 자동 전송, 전체 인물 생성, 이미지 생성 서비스, 게임 보상/전투 실행은 아직 연결하지 않는다.

## 구조
- `ui/association/quests.js`: 브라우저/Node 공용 순수 의뢰 엔진. 지역별 후보·랭크·보수·기한·모집 인원·48시간 붕괴 규칙을 결정한다. AI에게는 제목·사연·알려진 위험의 문장만 맡긴다.
- `electron/quest-board.cjs`: ChatGPT 구조화 응답 검사와 영구 보관. 기존 미마감 의뢰는 갱신으로 교체하지 않는다. 수락 기록 유지. 게임 시간은 테스트에서 6시간 단위로 이동한다. 다른 파티의 실제 활동/의뢰 완료/보상 지급/일반 핵 파괴 허가 발급은 후속 엔진 연결 대상이다.
- `electron/story-chat.cjs`: 현재 장면, 최근 12회 대화, 최대 900자 누적 기억을 입력해 다음 장면을 생성한다. 최근 100회 원문을 저장하고 오래된 내용은 누적 기억으로 이어간다. 기억은 AI 요약이므로 완전한 사실 보존을 보장하지 않으며 스탯/인벤토리 같은 확정 게임 상태를 덮어쓰지 않는다.
- `electron/codex.cjs`: 기존 도구 비활성·read-only·공식 구독 인증을 유지하고 JSON 스키마 응답 경로를 확장한다. 대사 전용 360자 제한은 기존 채팅에 유지하며 새 시스템은 별도 스키마/필드별 한도로 검사한다.
- `ui/association-ui.js`: 게시판 상세/수락과 자유 채팅 UI. 응답은 textContent로 표시하며 AI HTML/경로/코드를 실행하지 않는다.

## 저장과 검증
`userData/quest-board-test.json`, `userData/story-chat-test.json`에 별도 저장한다. 본편 슬롯으로 편입하거나 함께 내보내는 기능은 아직 없다. 임시 파일 후 교체하며 읽기 오류가 있는 원본은 덮어쓰지 않는다. 생성 중 중복 변경을 차단하고 실패/취소 응답은 기록하지 않는다. 이야기 요청 번호를 저장해 동일 요청 재시도 시 모델 호출을 반복하지 않는다. 리비전이 오래된 입력은 거절한다.

핵 무단 파괴는 불법. 협회의 핵 파괴 의뢰일 때만 파괴 권한이 부여된다. 이번 의뢰 후보에는 핵 파괴 의뢰를 넣지 않으며 전부 권한 없음으로 고정한다. 핵 파괴 48시간 후 기존 던전 의뢰가 마감되고 새 생태계의 조사·물자·호위 후보로 바뀐다.

설정/AI 기억/사용자 입력은 실제 행동 성공이나 보상 지급 근거가 아니다. 실제 게임 이벤트에 연결할 때 `candidates`의 테스트 상황을 저장 슬롯의 세계 상태로 대체하고, 검증된 전투/납품 결과로 완료를 판정해야 한다. 현재 UI는 해당 연결이 끝난 본편 기능으로 표시하지 않는다.

## v0.42.62 공통 던전 상태·의뢰 · 2026-11-24

`ui/dungeon/engine.js`는 게임 지명·캐릭터를 모르는 독립 상태 엔진이다. 호스트가 던전·연결 구역·몬스터·자원 식별자를 등록하고 실제 파티와 전투 결과를 전달한다. 생성은 같은 식별자에 한 번만 적용하고 회수품·구역 위협을 새 게시판/재입장/불러오기로 재생하지 않는다. `data.js`는 여섯 대륙의 기존 야생지역에 붙인 초기 호스트 구성이고, `model.js`가 게임 지도·도감·의뢰·권한·전투 증빙에 연결한다. 구역 이름·목표 구역·회수품은 데이터로 지정한다. 생성 시점과 구성은 개발용 초기값이며 별도의 세계관 확정 법칙으로 추가하지 않는다. 상세 도로·실내 지도 원화는 이번 범위가 아니다.

협회 게시판은 기존7종에 dungeon을 더하며, 현재 같은 대륙의 유효 던전과 관리 정책이 허용하는 목표만 ChatGPT에 제안한다. variant는 던전에서 survey/clear/recover/core 중 하나다. 관리 정책 preserve에는 핵 파괴 의뢰를 발행하지 않는다. remove에서는 협회가 핵 파괴 의뢰를 게시할 수 있으며 실제 수락·진입 때 해당 파티·계약·기한에 묶인 권한을 발급한다. 자유 대사만으로 권한·핵 파괴·완료/보상이 생기지 않는다. 조사·실제 전투 승리·회수품 소유·핵 파괴 주체 중 해당 증빙과 실제 입구 철수·귀환이 있어야 정산한다.

공통 엔진은 복수 파티를 등록해 동시 위치와 탐사·승리를 분리한다. 같은 사람이 다른 파티로 내부에 중복 진입하지 못하며 회수품은 먼저 확보한 한 파티 소유다. 공유 구역이 정리되어도 다른 파티에 전투 승리/보상 공적을 복사하지 않는다. 본편은 실제 계약 파티를 등록한다. 다른 NPC 파티의 자율 이동·전투 결과를 생성하는 AI는 아직 연결하지 않으며 존재하지 않는 파티를 채워 넣지 않는다.
