# 도시 구조 재설계 · v0.13.0 완료

반복되는 중앙 건물과 좌우 상점 구도를 폐기하고 모든36개 도시·108개 구역을 독립된 지형·동선·건물 덩어리로 다시 제작했다. 케스윅·미루카·티몬의3개 시범 재설계도 전체 도시 교체에 포함한다.

그림체의 선화·명암만 공유하며 건물 실루엣·길망·고저차·작업 공간은 도시별로 구분한다. 게임에서는 구역 이름과 시설 목록을 확인하며 그림과 관계없는 고정 좌표 표식을 쓰지 않는다.

최종 도시별 구성은 fantasy-rpg/geography/CITY-ATLAS.md, 실제 데이터와 그림은 fantasy-rpg/desktop/ui/map/city-district-data.js 및 ui/assets에 있다. 마을·야생지역의 추가 그림은 이번 도시 교체 범위에 포함하지 않는다.
