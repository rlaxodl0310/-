# 배경 구조 재설계 · 미공개 작업 초안

기존 일괄 생성은 사용자가 반복 구조를 지적하여 중단했다. 같은 화면 구도·가운데 큰 집·좌우 작은 집·정면 길을 공유하는 방식은 폐기한다. 깃발·색·소품 차이만으로 장소 차이를 표현하지 않는다. 중단된 그림은 자료로 보존하지만 전체 적용 완료나 배포 완료로 취급하지 않는다.

새 설계는 ① 지면(물·암벽·들판·성벽·부유섬), ② 길망(계단·나무다리·급경사·하역 램프·수로·회랑), ③ 건물 덩어리(낮고 긴 창고·원형 가마·수상 고상가옥·성벽 속 공간·절벽 작업장), ④ 지붕·재료·직업 활동, ⑤ 카메라 방향과 시야를 각각 정한다. 그림체의 선화·명암 처리만 공유하며 구도와 건물을 공유하지 않는다.

우선 케스윅·미루카·티몬의 세로3장면씩을 새로운 기준으로 제작한다. 케스윅은 성벽 계단길과 비대칭 관문, 미루카는 물·갈라지는 나무다리·갈대 지붕 수상 가옥, 티몬은 계단식 채굴장·작업 승강기·낮은 제련 설비·반지하 광부 주거를 중심에 둔다. 새 그림의 실제 건물 위치를 확인한 뒤 표식을 배치하며 이전의 고정3점 좌표를 그대로 쓰지 않는다.
