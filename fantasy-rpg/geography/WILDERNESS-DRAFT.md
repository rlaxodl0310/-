# 에르디아 · 야생지역 기초 초안

야생지역610곳은 대륙별 제작 목표다. 아래는 현재 이름과 간단한 지형을 작성한 큰 자연 권역18곳과, 그중 메아리 동굴망의 세부 장소10곳이다. 모든 목표 장소가 이미 만들어졌다는 뜻은 아니다.

| 대륙 | 자연 권역 | 지형·생태 느낌 |
| --- | --- | --- |
| 노르가르 | 백야 능선 | 최북단 방위선 너머의 설산·고원. 비행형·짐승형 몬스터 서식. 웨이브와의 구체 관계는 미조사. |
| 노르가르 | 검은솔 수림 | 중북부 침엽수림. 무리 사냥 개체와 나무 사이에 숨는 곤충형 몬스터. |
| 노르가르 | 갈라진 분지 | 동부 산맥 안쪽의 깊은 분지. 외부에서 서식 규모를 파악하기 어려움. |
| 엘세리아 | 겹숲 | 여러 층의 수관을 가진 거대한 숲. 식물형·곤충형 개체, 지상과 나무 위의 다른 위험. |
| 엘세리아 | 숨물 습원 | 물길·수심이 자주 바뀌는 습지. 슬라임·어류형·파충류형 개체. |
| 엘세리아 | 유리호 군락 | 지하 수로로 연결된 맑은 호수들. 호수마다 다른 생태. |
| 카르덴 | 붉은 절벽대 | 서북부의 층진 암벽. 파충류형·비행형 개체가 절벽과 동굴을 이용함. |
| 카르덴 | 메아리 동굴망 | 산 아래로 이어진 자연 동굴. 박쥐형·쥐형·곤충형 개체와 복잡한 소리 반사. |
| 카르덴 | 바람등 고원 | 산맥 위의 넓은 초원. 시야는 트이나 엄폐물이 적고 빠른 무리형 몬스터가 위협. |
| 세르바 | 열매비 숲 | 계절마다 먹이가 풍부해져 몬스터들이 몰리는 숲. |
| 세르바 | 뱀굽이 삼각주 | 큰 강이 갈라지는 하구. 어류형·파충류형과 물가 사냥 개체. |
| 세르바 | 마른등 언덕 | 비가 적은 내륙 구릉. 굴·바위틈에 숨는 개체, 식수 확보가 중요. |
| 아르켄시아 | 오래숲 | 개발에서 벗어난 대형 산림. 관리 외곽과 깊은 몬스터 서식 구역의 차이. |
| 아르켄시아 | 쌍물 협곡 | 두 강이 합류하는 깊은 협곡. 급경사·비행 몬스터와 우회 이동. |
| 아르켄시아 | 잠긴 평야 | 주기적인 범람 저지대. 물이 빠진 뒤 진흙·웅덩이에도 개체가 남음. |
| 아엘리온 | 구름밑 군도 | 주섬 아래의 작은 부유섬들. 구름에 가려지고 비행 몬스터가 쉬어 감. |
| 아엘리온 | 돌바람 벌판 | 북동부의 노출된 바위 지대. 강풍·절벽·바위틈 생태. |
| 아엘리온 | 매달린 숲 | 주섬 외곽과 인접 부유섬의 숲. 수직 이동과 추락 위험. |

## 메아리 동굴망 · 세부 장소 초안

| 장소 | 지형·느낌 |
| --- | --- |
| 박락 입구 | 낙석이 잦은 외곽 동굴. 작은 곤충형·쥐형 개체. |
| 마른 수로 | 물이 빠진 좁은 통로. 우회로가 적음. |
| 물먹은 굴 | 지하수가 차오르는 구역. 슬라임·어류형 개체. |
| 뒤집힌 돌방 | 낙석이 통로를 여러 층으로 나눈 공간. |
| 검은 천장 | 높은 천장에 박쥐형 개체가 밀집한 구역. |
| 뿌리 틈 | 지상 나무뿌리가 내려와 식물형 개체도 나타나는 곳. |
| 바늘 회랑 | 뾰족한 암석이 빽빽해 큰 무기를 쓰기 어려운 통로. |
| 낮은 숨길 | 몸을 숙여 통과해야 하는 좁은 길. |
| 푸른 웅덩이 | 광물로 물빛이 푸른 연못. 수질·생물은 조사 대상. |
| 먼울림 공동 | 소리가 멀리 돌아 들려 위치를 오판하기 쉬운 넓은 공동. |

자연 권역과 세부 장소는 상하위 관계다. 상위 권역에 진입했다고 하위 장소가 모두 해금되지 않는다. 자연 동굴망을 자동으로 던전으로 분류하지 않으며, 생태 설명만으로 특정 성급·확정 개체 수·정수 효과를 추가하지 않는다.
