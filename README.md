# 캠퍼스 생존 시뮬레이션

대학교의 일상·관계 형성과 좀비 아포칼립스 생존을 결합하는 게임의 초기 개발 저장소입니다.
최종 엔진 방향은 Unity입니다. 현재 구현은 일상 선택 흐름을 확인하는 별도 웹 시제품이며 Unity 프로젝트나 3D 플레이가 아닙니다.

## 실행

Node.js와 Python 3가 필요합니다. 웹 시제품에 외부 패키지를 설치할 필요는 없습니다.

```sh
npm start
```

저장소 루트에서 실행합니다. 서버의 첫 화면을 열면 `/prototype/`으로 자동 이동합니다. `PORT` 환경변수로 포트를 지정할 수 있고 기본값은 8000입니다. 서버는 미리보기 연결을 위해 `0.0.0.0`으로 수신합니다. index.html을 파일로 직접 열지 말고 HTTP 서버를 사용합니다.
외부 배포는 하지 않았습니다. 저장 슬롯은 사용 중인 브라우저의 해당 사이트 저장소에만 보관됩니다.
브라우저 데이터 삭제나 다른 기기로의 이동 시 저장은 유지되지 않습니다.

## 서버 없이 실행

이 채팅의 온보딩 UI에서는 로컬 웹 미리보기를 지원하지 않습니다. 미리보기 패널 오류가 게임 코드 오류라는 뜻은 아닙니다.
다음 명령으로 이미지·스타일·코드를 포함하는 단일 HTML 파일을 만들 수 있습니다.

```sh
python3 prototype/build_standalone.py /tmp/campus-demo.html
```

생성한 파일을 다운로드하여 데스크톱 브라우저로 열면 됩니다. 저장 기능은 브라우저의 로컬 파일 저장소 허용 여부에 영향을 받습니다.
미리 생성한 파일은 [demo/campus-demo.html](demo/campus-demo.html)입니다. GitHub에서는 파일 다운로드 기능으로 저장한 뒤 여세요.
압축 배포본 [campus-demo.zip](https://github.com/rlaxodl0310/-/raw/refs/heads/main/demo/campus-demo.zip)을 다운로드하고 압축을 푼 뒤 `campus-demo.html`을 Chrome 또는 Edge에서 열 수도 있습니다. GitHub의 코드 보기 화면 자체에서는 게임 UI가 실행되지 않습니다.
단일 HTML의 화면·활동·저장은 HTTP로 검증했습니다. 클라우드 Chromium 정책이 file URL을 차단해 로컬 파일 직접 열기는 이 환경에서 검증하지 못했습니다.
다운로드판 이미지 포장은 큰 데이터 URL을 CSS 변수에 넣지 않고 직접 참조하도록 수정했습니다. 브라우저 검증은 버튼 표시뿐 아니라 배경·초상화 이미지의 실제 로딩도 검사합니다.

## 플레이 범위

1~3일차에 13:00 등교 후 자유행동합니다. 이동·탐색·대화 여러 번을 묶어 약 30분씩 시간이 흐르며, 짧은 대답마다 시간이 차감되지 않습니다. 긴 활동은 현재 시각부터 실제 소요 시간만큼 진행합니다. 정해진 16:00 시작이나 하루 한 활동 제한 없이 여러 일을 하거나 탐색만 할 수 있습니다. 18:00 이후에도 머물 수 있고 귀가는 직접 선택합니다. 오전 수업과 실시간 3D 이동은 아직 구현하지 않았습니다.
등교 → 원하는 장소 방문 → 현장에서 생기는 대화·자유행동 → 계속 탐색하거나 직접 귀가 → 다음 날로 진행합니다.
탐색은 정적 배경과 버튼을 이용합니다. 모든 메뉴는 전용 화면으로 전환됩니다.
합주·음악 작업·주변 탐색·산책은 매일 선택할 수 있습니다. 봉사 준비·사진 정리·전시 준비·축구 체험 같은 학교 행사는 해당 날짜와 현장 조건에 따라 선택적으로 참여합니다.
연결 통로 운반은 1일차 탐색 또는 2일차 산책으로 길을 알아둔 경우에만 열립니다.
태이가 불참해도 봉사 사건과 참여자 간 관계 변화는 내부 세계 상태에 반영됩니다.
한서연·차여경·박소율과 대화할 수 있습니다. 성격·친밀도·호감도·신뢰·대화 기억에 따라 반응과 후속 질문이 달라집니다.
대화는 매 답변마다 공통 질문으로 돌아가지 않고 커피·사진·글쓰기·일과 후의 이야기 등 하나의 주제를 여러 차례 이어갑니다. 태이의 실제 대사와 상대의 반응을 함께 보여줍니다.
NPC끼리도 공개 가능한 경험을 공유합니다. 소율과 사진을 본 뒤 서연이 소율에게 이야기를 듣고 다음 만남에서 언급할 수 있습니다. 직접 경험과 전해 들은 정보는 구분하며 사적인 초안·개인 만남의 결과는 공유하지 않습니다. 반복된 활동 불참 이야기는 NPC의 다음 제안에 영향을 줄 수 있지만, 자신의 경험과 기존 신뢰를 함께 판단하고 관계 점수를 일괄 차감하지 않습니다.
NPC는 현재 할 일, 관심, 신뢰와 남은 불편함에 따라 먼저 묻거나 대화를 미룹니다. 호감이 높아도 신뢰가 낮으면 사적인 초안은 공개하지 않을 수 있습니다.
태이는 동아리 미가입 상태로 시작합니다. 봉사단·축구·음악 동아리의 안내를 읽고 직접 가입할 수 있으며, 활동을 먼저 체험할 수도 있습니다. 처음 만나는 인물의 이름은 모르고, 실제 만남이나 가입 후 공지를 통해 알게 됩니다. 이름 지식과 친분은 별개입니다.
장소에 도착하면 대화 상대 목록 대신 누군가 자기 일을 하던 장면을 마주칩니다. 영수증을 건네거나 빈자리를 물으며 말을 섞을 수 있고, 그냥 지나갈 수도 있습니다.
게시판·창가·휴게공간 같은 동선을 고르면 실제 그 시간에 있는 사람과 장면이 연결됩니다. 지나친 장면은 같은 시간대에 다시 대기 상태로 나타나지 않습니다.
중간에 나온 취향은 그 말을 들은 캐릭터만 기억하며 다음 날 메시지에 반영합니다. 진행 중인 대화와 선택도 저장됩니다.
친밀도 상승만으로 반말로 바뀌지 않습니다. 충분히 친해진 뒤 말투 변경을 제안하고 상대가 동의해야 합니다. 관계 비교용 예시는 이미 말놓기에 동의한 상황을 포함합니다.
선택형 대본과 관계 판단 로직을 사용하는 시제품이며 외부 언어 모델이나 API 키는 필요 없습니다. 자유 입력 대화나 무제한 대사 생성은 아직 없습니다.
서연과 소율이 나누는 대화에도 참여할 수 있습니다. 참석 약속은 실제 활동 선택과 이후 대화에 영향을 줍니다.
관계별 차이는 메뉴에서 '서먹한 사이 / 친한 동료 / 호감이 쌓인 사이' 예시를 새로 시작해 비교할 수 있습니다. 현재 진행은 초기화되며 기존 저장 슬롯은 유지됩니다.
태이와 대화 상대는 정면 초상화로 표시합니다. 외형은 현재 참고용이며 최종 캐릭터 디자인은 아닙니다.
2일차에는 여경은 학생회관, 서연은 카페, 소율은 도서관에 있습니다. 장소의 생활 장면에서 실제 그 시간에 있는 인물과 마주칩니다. 인물별 대화 버튼은 표시하지 않습니다.
NPC가 성격·친분·호감·신뢰·미해결 갈등·이미 수락한 일정에 따라 먼저 약속을 제안합니다. 동아리 가입도 활동 참석을 자동 확정하지 않으며, 휴대폰 일정에서 제안을 수락·거절합니다. 태이도 대화 중 함께할 시간을 물을 수 있고, 상대는 거절할 수 있습니다. 개인 약속은 정한 날짜·시간대·장소에서 실제로 교류해야 이행됩니다. 겹치는 일정 경고와 미리 연락해 취소하는 기능을 제공합니다.
현재는 3일의 예정된 활동, 관계에 따른 조건부 사건, 이동 중 마주침을 연결한 시제품입니다. 범용 NPC 자율 계획 시스템, 모든 캐릭터 일정, 전투, 실제 3D 이동은 아직 없습니다.
저장 버전은 6이며 동아리 가입·제안 상태·NPC의 제안 판단 기록을 함께 저장합니다. 기존 저장의 관계·기억·이미 알고 있던 이름은 유지하고 동아리 소속을 새로 강제하지 않습니다. 마주친 장면에서 말을 섞었는지 지나쳤는지도 저장합니다. 이벤트의 결과·조건·알게 된 경위와 활동 참여 방식도 저장합니다. 이전 저장에서 이미 끝난 사건은 다시 실행하지 않습니다.

## 장면을 따라 진행하기

처음에는 학교에 도착해 학생회관·도서관·카페 중 원하는 곳으로 이동하거나 귀가할 수 있습니다. 특정 알림이나 만남을 첫 할 일로 지정하지 않습니다. 물품 상자·연습실 소리·펼쳐진 사진·현장 안내처럼 실제 장소에서 접한 것이 다음 행동으로 이어집니다.
커뮤니티는 휴대폰 → 학내 커뮤니티에서만 확인합니다. 일정에는 실제 제안·수락한 약속과 완료한 활동을 표시하며, 개인 루틴을 예정 일정으로 자동 등록하지 않습니다. 구체적인 일을 고르면 소요 시간과 약속 충돌을 확인하고, 시작하지 않으면 직전 장면으로 돌아갑니다.

## 학내 커뮤니티

휴대폰의 `학내 커뮤니티`에서 가상 서비스 캠퍼스톡을 확인합니다. 전체·자유·모집·공지 글을 읽고 모집 안내와 체험으로 이어집니다.
가상 작성자들이 관심사·활동 시간대·작성 간격에 따라 글을 쓰고 댓글·글쓴이 답글·공감이 시간차를 두고 붙습니다. 게임 시간 경과와 활성 게임 창의 배경 갱신으로 진행하며, 태이의 행동 시계는 따로 유지합니다. 읽는 목록을 갑자기 바꾸지 않고 새 글·댓글 도착을 알려줍니다.
작성 상태와 예약된 반응을 저장합니다. 날씨·공개 행사에 맞는 글감을 쓰고, 인물의 사적 정보나 미래 사건을 노출하지 않습니다. 익명 이슈 글은 미확인 전언이며 현장 목격과 구분합니다. 외부 AI API 없이 작성 규칙과 글감을 이용하는 게임 내 생활 시뮬레이션입니다.

## 일상 속 이상 징후

3일차에는 행사 지원 인력 지연 안내, 신뢰하는 인물의 조심스러운 연락, 실제 장소에서 확인하는 출입구 통제·자료실 운영 변경·구급차를 연결합니다. 원인을 바로 공개하지 않고 기존 대학생활과 약속을 유지합니다.
학생회관 뒤편 출입문·도서관 로비·카페 창밖을 살펴볼 수 있고, 확인한 내용은 휴대폰의 `확인한 일`에서 출처별로 읽을 수 있습니다. 안내를 접한 뒤 `교내 안내 확인`에 오후를 쓸 수도 있으며, 다른 활동에 한 약속과 충돌할 수 있습니다.
3일차 배치는 검증용이며 최종 발발 날짜를 확정하지 않습니다. 현재 플레이는 대학생활 구간이고 감염 판정이나 실제 좀비 전투는 포함하지 않습니다.

## 인물별 판단과 동행

이상 징후를 접한 NPC는 자신이 본 것과 전해 들은 내용을 구분하고, 전달자 신뢰와 맡은 일을 함께 판단합니다. 태이는 실제로 아는 내용을 골라 전달할 수 있으며, 말하지 않은 관찰이 모든 NPC에게 퍼지지는 않습니다.
여경은 물품·인원 조율을 우선하고, 서연은 확인할 정보와 동선을 챙기며, 소율은 가까운 사람에게 확인하면서 출력물을 먼저 마무리합니다. 실제 준비 상태와 받은 정보에 따라 연락·이동·동행 제안이 달라집니다. 호감이 높아도 책임이나 기존 약속 때문에 거절할 수 있습니다.
수락한 동행은 `교내 안내 확인` 활동에서 실제 참여와 방문한 장소의 경험으로 이어집니다. 현재는 세 인물의 3일차 판단을 연결한 시제품이며 이후 발발·탈출 행동은 후속 범위입니다.

## 날씨

맑음·흐림·비·강한 비와 게임 내 예보를 제공합니다. 기본 3일 예시의 2일차에는 비가 옵니다. 날씨표는 저장되며 실제 기상 정보와 연동하지 않습니다.
상단 날씨 버튼이나 휴대폰에서 예보를 보고, 학생회관에서 공용 우산을 대여·반납할 수 있습니다. 우산은 실제 소지품과 획득 알림에 반영됩니다.
우천 시 일부 NPC의 선택적 외출을 줄이고, 야외 이동·활동에는 준비 상태를 반영합니다. 축구 체험은 실내 훈련으로 대체하며 같은 참석 약속을 유지합니다. 강한 비로 취소된 야외 약속은 개인 불이행으로 처리하지 않습니다.
메뉴의 날씨 비교 예시에서 네 날씨를 확인할 수 있습니다. 실제 계절·장기 무작위 날씨·젖음/체온/피로는 아직 구현하지 않았습니다.

## 세 종류의 이벤트

- 일정형: 봉사 준비·사진 선정·전시 준비는 태이가 불참해도 진행합니다. 관계와 참여 방식에 따라 공동 구성·형식 우선·별도 준비 등으로 결과가 달라집니다.
- 조건형: 신뢰와 함께한 경험이 있으면 소율에게 문구 검토 메시지가 올 수 있습니다. NPC끼리 연락하거나 미해결 의견 차이가 남는 사건도 조건에 따라 진행합니다.
- 상황형: 실제 동선과 인물 위치가 맞을 때만 마주칩니다. 메시지를 읽었다면 다음 날 자료실에서 보이는 인쇄물이 무엇인지 알아볼 수 있습니다.

봉사·사진 정리·전시 준비의 상세 화면에서 참여 방식을 고를 수 있습니다. 초안 검토는 도착만으로 완료되지 않고 실제로 의견을 나눠야 결과에 반영됩니다.
전시에 불참해도 앞서 한 도움이 결과를 바꿀 수 있지만, 그 결과는 당사자에게 듣기 전까지 자동 공개하지 않습니다.

좀비 사태 이후에도 세 유형을 같은 이벤트 실행 구조로 사용합니다. `survival-event-examples.js`에는 경계 교대·피로에 따른 부탁·막힌 통로의 예시를 넣고 테스트했습니다. 현재 다운로드판에는 발병이나 생존 구간 UI가 아직 없습니다.
