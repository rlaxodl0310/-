# 탱탱 공통 코어 개발

- 이 디렉터리가 모든 프로젝트에서 재사용하는 원본이다. 게임 이름·지도·캐릭터·의뢰·보상·외부 앱 업무 규칙을 src/core.js에 넣지 않는다.
- 새 기능은 프로젝트 어댑터, 모델 제공자, 저장소, JSON 통신 연결로 확장한다. 출처/프로젝트 분리와 호스트의 실제 적용 권한을 유지한다.
- 모델 제안이나 승인 영수증을 외부 작업 실행/사실 확인으로 표현하지 않는다. 자체 훈련된 언어 모델로 표시하지 않는다.
- 코어 변경 후 `npm --prefix tangtang test`, `node fantasy-rpg/desktop/scripts/sync-tangtang.cjs`, `npm --prefix fantasy-rpg/desktop test`를 확인한다.
- 공개 npm 배포/외부 서비스 연결은 요청 없이 하지 않는다. 새 프로젝트의 인증/개인 데이터/세계관을 다른 프로젝트에 자동 공유하지 않는다.
